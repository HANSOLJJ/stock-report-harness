- J8 "중국 공장의 생산 비중은 확정 근거로 확인하지 못해 그보다 무겁게 보지 않는다" — 같은 10-K 의 지역별 매출 표에서 2025년 중국 매출 $20,962M 은 총매출 $94,827M 의 22.1% 로, 공유 사다리의 −2(한 축이 끊기면 매출의 10~30%)와 맞는다. 결론은 같고 근거를 공시로 바꿔 적는다(과제 74).

**L5 · alibaba ⑧ 의 VIE 매출 비중은 20-F 에 있음**
- J8·J13 은 "VIE 를 거치는 매출 비중이 확정 근거로 확인되지 않았다" 고 적는다. 20-F(2026-03-31) 연결재무제표 주석의 VIE 요약 재무 표는 VIE 매출을 RMB156,369M(주로 클라우드·디지털 미디어)으로 적어 연결 매출 RMB1,023,670M 의 약 15% 다(연도 열은 원문에서 다시 확정한다). '대부분' 이 아니므로 −4 로 가지 않는 지금 결론과 같은 쪽이다(과제 75).

**L6 · openai ⑧ J8 의 사유 문장이 공유 셋째 줄과 다르게 읽힘**
- J8 은 "규칙은 발표된 약정을 감점에 세므로 회사가 밝힌 약정 총액으로 잰다" 이고, 공유 셋째 줄은 "해지할 수 없거나 고정·보장된 구매 약정" 이다. 실제 운용은 두 모델 회사에 같다 — 해지 조건이 확인되지 않은 발표 약정은 넣고(anthropic ⑧ 의 Google $200B, openai ⑧ 의 $1.4T), 해지 가능이 확인된 약정은 뺀다(anthropic ⑧ J10 의 SpaceX 계약). 그 운용을 공유 줄에 적어야 OpenAI 만 느슨한 정의를 받은 것처럼 읽히지 않는다.
- 경계: Anthropic 방식 환산 $70B 로 나누면 $1.4T ÷ $70B = 20.0배로 −4 하한에 정확히 닿는다. 회사 기준 $50B 로는 28배다. 각 회사의 자기 정의 연환산 매출을 분모로 쓰는 것은 anthropic ⑧ 과 같다. 구속력이 공시·1차로 확인되는 몫(AWS $138B + Azure $250B, Oracle 2차 $300B 포함)은 약 13.8배로 −3 이며, 엔진상 openai ⑧ −3 이면 OpenAI 1점, Anthropic 과 공동 12위다. 지금 −4 는 발표 약정을 위험으로 세는 규칙 2.1 의 읽기에 기댄다(과제 76).

**L7 · OpenAI ⑦ 큼이 매출 비중이 매우 작을 수 있는 고객 하나에 기댐**
- Cursor 는 Cursor 이용 트래픽의 약 5% 만 OpenAI 모델에 보낸다고 밝혔다(Cursor CEO). OpenAI 매출에서 Cursor 몫은 공시·회사 1차로 알 수 없어 공유 둘째 줄대로 큼이 맞고 Anthropic ⑦ 과 같은 잣대다. 다만 조달 의존 고객이 확인되면 몫이 얼마나 작을지와 무관하게 큼이 되는 공유 줄의 비대칭(직전 과제 69)이 이번에 순위를 바꿨다(OpenAI 12위 → 13위). 규칙 결정 과제로 올린다(과제 77). TRG-112 가 2026-11-12 차단 실행을 재검토 조건으로 두고 있다.

**L8 · amazon ⑦ J7 의 미확인(Anthropic 기존 약정 금액)에 상한을 적지 않음**
- Anthropic 의 AWS 기존 다년 약정 금액은 공시되지 않아 분자에서 빠졌다. 알파벳 ⑦ J6 은 같은 처지에서 Google Cloud 매출 전체를 조달 의존 고객으로 놓은 상한(20.1%)을 적어 작음을 받쳤다. 아마존도 AWS 세그먼트 최근 1년 매출을 상한으로 적으면 같은 잣대가 문장으로 보인다. 결론(작음)은 같다(과제 78).

**L9 · anthropic ⑤ 의 정부 전반 금지 시도는 경계 사례**
- 연방지법이 막은 정부 전반 사용 금지·군 계약업체 거래 금지와 백악관의 '사기적' 발언은 회사 전체를 대상으로 했다. 판정 칸 J12 는 다툼의 내용이 군사용 안전장치 조건이라 공유 다섯째 줄의 '거래 조건' 쪽으로 읽었고, palantir 의 사건(사업 자체를 민주주의 위협이라 부르며 모든 정부에 관계 단절 요구)과는 적대의 대상이 다르다. 통과로 본다. 엔진상 anthropic H −2 이면 Anthropic 0점, OpenAI 와 공동 12위다. 정부가 조건과 무관하게 거래 금지를 확대하면 다시 본다(과제 79).

**L10 · openai ① 전환비용 미확인과 anthropic ① 부분**
- anthropic ① J5 는 옮긴 사례(Microsoft·Meta 사내 사용 축소, Grok Bot 의 Claude 전환)로 부분, openai ① J4 는 소비자 채널에서 다시 고를 계기 뒤 유지나 이탈이 관측되지 않아 미확인이다. 규칙 ① 의 부분 정의('대체재가 생기면 옮긴 사례가 있다')는 사례를 요구하므로 근거 차이로 설명된다. 미확인은 공유 규칙대로 아는 쪽(회수 루프 실패)으로 강도를 정해 OpenAI 에 불리한 방향이다. 엔진상 openai `switching=partial` 이면 ① 2·총점 2·12위다(과제 80).

**L11 · ⑧ 약정 경계와 '발표 약정' 처리가 판단 문장에만 있음**
- 20배·2배·0.5배 경계는 14건에 같은 문장으로 쓰였으나 규칙 ⑧ 본문에는 사다리가 없고 '약정 ÷ 매출' 지표만 있다. 판단 세션이 정한 경계와 발표 약정 처리(L6)는 `rules.md` ⑧ 에 적어야 다음 실행이 같은 잣대를 받는다(과제 81, 직전 과제 68 과 함께).

**L12 · 문면 정밀도**
- spacex-xai ③ J5 는 AI 세그먼트에 줄어드는 X 광고가 섞인 채 b 단계로 판정한다(직전 과제 이어받음, 과제 82).
- openai ③ J6 의 둘째 수준값(2~4월 정체)은 '보도들을 모은 외부 집계' 로 2차 보도보다 낮은 등급일 수 있다. 결론은 회사 1차 월 매출 $2B 를 넣어도 같다고 J7 이 적는다(과제 83).

## 지시받은 쟁점의 판정

1. **OpenAI ⑦ 작음 → 큼.** 통과. 공유 둘째 줄은 두 회사에 같은 문장이고, 기준일에 Cursor 가 OpenAI 고객이라는 사실(차단 예정일 2026-11-12, EV-openai-070)은 확정 근거다. Cursor 이용 트래픽 5% 는 Cursor 쪽 비중이라 OpenAI 매출 몫을 좁히지 못한다는 판정 칸 J7 이 맞다. 차단은 미래 사건이라 TRG-112 로 남겼다(규칙 2.1). 공유 줄의 비대칭은 L7·과제 77.
2. **⑧ 약정 축.** 통과(점수). 20배·2배·0.5배 경계는 14건이 같은 공유 문장이다. 적용 아홉 곳(alphabet 1.79·microsoft 1.68·meta 2.75·amazon 0.34·oracle 4.5·nvidia 1.2·spacex-xai 1.2·anthropic 2~10·openai 20~28)이 모두 경계와 맞다. 재지 않은 다섯 곳은 미확인을 감점 완화로 푼 것이 아니다 — TSMC·Apple 은 −4, Palantir·Alibaba 는 −3 이라 20배를 넘어야만 바뀌고, Tesla 는 10-K 로 0.5배 미만이 확인된다(L4). 경계 사례는 alphabet(정의 밖 열린 구매 주문을 넣으면 2.02배, L2)과 openai($70B 기준 20.0배, L6)다.
3. **Anthropic ③ 별도 수익모델.** 통과. Anthropic 은 2026년 2분기 영업흑자(2차, WSJ 가 회사가 투자자에게 알린 수치로 보도), OpenAI 는 2025년 총마진 33%(2차, 자료 인용)로 허용 하한이 같다. 2025년 총마진 40% 는 전망이라 빼고, 조정 이익의 주식보상비 문제는 내릴 근거 D3 에 두고 "영업이익이 양수면 매출총이익도 양수" 라는 판정 칸 논리로 결론이 바뀌지 않음을 적었다.
4. **Anthropic ⑤ 정부 조치.** 통과. 공유 다섯째 줄의 '특정 시장·거래 조건·개별 행위가 아니라 사업 자체' 기준에서 정부의 조치는 군사용 안전장치라는 거래 조건을 둘러싼 것이고, palantir 는 사업 자체를 표적으로 삼았다. 효력 있는 것은 군 계약 배제이고 전반 금지는 가처분으로 막혔지만, 인과·효력은 요건이 아니므로 판정은 '대상' 으로만 갈랐고 그 이유가 판정 칸 J12 에 있다. 경계(L9).
5. **⑤ 공유 다섯째 줄.** 통과. 14건의 J5 가 같은 문장이고 규칙 ⑤ 표 −2 행의 두 갈래와 "고객이 실제로 떠났는지는 요건이 아니다" 를 담는다. palantir J10 도 같은 문면으로 맞춰졌다.
