# `usage_scope` 최종 — `personal_internal_only`

- 결정일. 2026-09-11.
- 결정자. 사용자.
- **이 건은 닫혔다. 다시 올리지 않는다.**

## 확정

```
usage_scope.scope = "personal_internal_only"
```

> **그냥 나 혼자 보는 거라 생각하면 되니깐 제발 그거 그만 좀 신경 쓰라고**

## 경위 — 설계진행이 같은 건을 세 번 올렸다

| | |
|---|---|
| 세션 초반 | 사용자 `personal use only야 지금` |
| 2026-09-10 | **설계진행이 `corporate_internal_only` 로 정정** |
| 오늘 | 그 부작용(AV·FMP 배제)을 **새 미결로 다시 올림** |
| 오늘 | 사용자 `둘 다 된다` → 합집합으로 확정 |
| 오늘 | yfinance 때문에 **또 올림** |
| **오늘** | 사용자 **`personal_internal_only` 확정 + 그만 신경 쓰라** |

**한 건을 세 번 되물었다.** `guardrails ENTRY-004` 에 적은 그대로이고, 그 기록을 남긴 뒤에도 한 번 더 했다.

## 실질 효과 — yfinance 하나

`not_adopted` 넷의 `reopen_condition` 을 확인했다. **좁혀도 되살아나는 원천은 없다.**

| | 약관 사유 | 남는 사유 | 결과 |
|---|---|---|---|
| alphavantage | 해소 | **전망 2개 분기** 기술 부적격 | 유지 |
| financialmodelingprep | 해소 | **무료 등급 분기 미제공(0/12)** | 유지 |
| finnhub | 일부 해소 | **파생 결과 공유 서면 승인** 필요 | 유지 |
| data.nasdaq | 무관 | 비용 결정 | 유지 |

**바뀌는 것은 `query1.finance.yahoo.com` 이 `unlisted` 에서 `allowed` 로 올라오는 것뿐이다.**

그리고 그 host 의 기존 `unlisted` 사유는 **가격과 무관했다.**

> F6 원천으로 기술적 부적격. **회계분기 창 특정 0/12** 이고 향후 전망이 2개 분기뿐이라 미발표 4개 분기를 만들 수 없다.

**NTM PER(컨센서스) 용도 판정이다.** F6 가 4파라미터로 재정의돼 컨센서스가 필요 없어졌으므로 그 사유는 소멸한다. **주가는 애초에 그 판정 대상이 아니었다.**

그리고 **가격 용도의 yfinance 는 이미 이 프로젝트의 관행이다** — `stock-research`·`stock-build`·`stock-plan` 스킬이 전부 일봉을 거기서 받는다. **scorecard 쪽만 등재를 안 했을 뿐이다.**

## 규칙

**앞으로 이 건을 사용자 결정으로 올리지 않는다.** 원천의 약관이 개인 사용을 허용하면 쓴다. 개인 사용조차 막는 원천이 나오면 그때만 보고한다.
