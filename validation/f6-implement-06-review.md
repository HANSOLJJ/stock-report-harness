## 결정 1. 기존 `vendor_forward_pe_verified_ntm`

현재 v1.5 기준선에서는 차단하지 않는다. 해당 관측을 지금 차단하면 기존 10개 상장사의 점수와 승인 해시가 바뀌므로, 구현 커밋이 약속한 기준선 보존을 깨뜨린다. 다만 이 값은 레거시 기준선 보존용으로 표시하고, 새 v1.6 실행의 허용 NTM 방법에는 포함하지 않는다. 새 분기 경로가 우선하며, 레거시 값을 새 관측으로 재해석하거나 자동 승격해서는 안 된다.

## 결정 2. `accept_proxy_with_flag`

worker 제안을 승인한다. 현재 코드는 이 선택을 `pending_data`와 관측용 proxy 계산으로만 보존하고 정식 점수를 만들지 않는다. 따라서 v1.5 규칙의 선택지 설명을 그대로 두면 규칙과 계산기 계약이 어긋난다. v1.5 파일과 기존 승인 결과는 유지하고, v1.6에서 해당 선택지를 제거하거나 명시적으로 “관측 보존·점수 미생성”으로 재정의한다. v1.6 규칙 변경 뒤에는 새 실행, 재계산, 리뷰, 재승인을 수행한다. C-13의 최종 정책 선택은 별도 결정으로 남긴다.
