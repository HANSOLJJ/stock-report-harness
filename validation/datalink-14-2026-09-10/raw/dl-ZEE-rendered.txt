WHAT IS ZACKS PROPRIETARY\nBNRI\nACCOUNTING METHODOLOGY?\n\nAnswer:– In 1980, Zacks identified a set of non-recurring items(NRIs) that should be excluded from operating earnings, in order to provide the most meaningful EPS surprises and to facilitate comparability of valuation metrics across companies and over time. Since then, Zacks has been adjusting actual reported EPS and analyst estimates of EPS to reflect NRIs and to create the Zacks actual EPS before non-recurring items (BNRI), the consensus estimate of Zacks EPS BNRI, and the EPS surprise. (Note: starting as of 2008, Zacks has treated stock-based compensation as a recurring item to be included in operating earnings and does not exclude it as an NRI when calculating EPS BNRI.) BNRI consensus is best used for company to company valuation analysis because the estimate defi nition used is the same across all companies.\n\n2. HOW DOES ZACKS MAKE SURE THAT ESTIMATE AND RATINGS REVISIONS ARE QUICKLY AND ACCURATELY INCORPORATED INTO THE ZACKS CONSENSUS?\n\nAnswer: Most of the contributing brokers send revisions to Zacks through electronic data feeds which are programmatically parsed and instantly fed into the consensus database. Some small boutique firms send their revisions to Zacks by email and those revisions are entered into the consensus database within 24 hours of receipt, except data that has been flagged and corrected as described below. Corrected data is available within 48 hours of receipt.\n\n3. HOW DOES ZACKS MANAGE EARNING ESTIMATES TO FACILITATE COMPARISONS BETWEEN ANALYSTS AND TIME PERIODS?\n\nAnswer: Zacks consensus earnings estimates are calculated to reflect true operating earnings. That means non-recurring items are filtered out of earnings estimates to allow for apples-to-apples comparisons between analysts and time periods.\n\nSample Data\n\nFor sample data, use the API call below, using the Table Code for the table being requested.\nhttps://data.nasdaq.com/api/v3/datatables/{Table_Code}?api_key=<YOURAPIKEY>\nEx:\nhttps://data.nasdaq.com/api/v3/datatables/ZACKS/EE?api_key=<YOURAPIKEY>\n\nThe data samples for the table\nZACKS/EE\n,\nZACKS/LTG\nand\nZACKS/MT\ninclude data for the tickers in the following list.\n\nTicker\tCompany Name\nAAPL\tAPPLE INC\nAXP\tAMER EXPRESS CO\nBA\tBOEING CO\nCAT\tCATERPILLAR INC\nCSCO\tCISCO SYSTEMS\nCVX\tCHEVRON CORP\nDD\tDU PONT (EI) DE\nDIS\tDISNEY WALT\nGE\tGENL ELECTRIC\nGS\tGOLDMAN SACHS\nHD\tHOME DEPOT\nIBM\tINTL BUS MACH\nINTC\tINTEL CORP\nJNJ\tJOHNSON & JOHNS\nJPM\tJPMORGAN CHASE\nKO\tCOCA COLA CO\nMCD\tMCDONALDS CORP\nMMM\t3M CO\nMRK\tMERCK & CO INC\nMSFT\tMICROSOFT CORP\nNKE\tNIKE INC-B\nPFE\tPFIZER INC\nPG\tPROCTER & GAMBL\nTRV\tTRAVELERS COS\nUNH\tUNITEDHEALTH GP\nUTX\tUTD TECHS CORP\nV\tVISA INC-A\nVZ\tVERIZON COMM\nWMT\tWALMART INC\nXOM\tEXXON MOBIL CRP\nAPI Usage\nAPI\nRecommended\nSQL\nPython\nAuthentication\n\nYou must log in to view usage examples and make API calls.\n\nLoginSign Up\nData Export\nAuthentication\n\nYou must log in to view usage examples and make API calls.\n\nLoginSign Up\nRecommended Datasets\nNasdaq Basic\n\nProvides best bid and offer quotations from the Nasdaq execution system as well as trade data from the Nasdaq execution system and FINRA/Nasdaq Trade Reporting Facility (TRF).\n\nPremium\nTables API\nNasdaq Last Sale Plus\n\nComprehensive, affordable, access to all Nasdaq U.S. market last sale data and consolidated volumes.
