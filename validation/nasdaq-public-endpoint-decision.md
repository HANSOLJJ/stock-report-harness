# Nasdaq 공개 엔드포인트 배제 결정

- 결정일: 2026-09-09
- 대상: `api.nasdaq.com/api/analyst/{TICKER}/earnings-forecast`
- 결정: 생산 원천에서 배제

해당 무료 엔드포인트는 자동 수집과 콘텐츠 추출 제한이 있어 관측 등록, F6 점수 계산, HTML 리포트 근거로 사용하지 않는다. 이미 확보된 샘플은 조사 증거로만 보존한다.

Nasdaq Data Link `ZACKS/EE`·`ZACKS/EEH`는 별도 계약 후보로만 남긴다. 자동 수집, 파생 데이터 계산, 외부 배포, 보관 조건이 서면으로 확정된 경우에만 재검토한다.
