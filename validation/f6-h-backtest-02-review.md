# F6-H 백테스트 재검토

- 대상 커밋: `bc92cfb`
- 판정: 합산 오차 분석 PASS, 정식 F6-H 점수·밴드 채택 보류

이번 결과는 F6-H 전체 합계(2A 실제 + 2E 전망)를 동일 4개 분기의 실제 합과 비교했다. 합산 APE 중앙값은 4.35%, 평균은 11.13%이며, 실제 EPS 합이 0 이하인 SPCX는 APE에서 제외 사유를 기록했다. 가격은 검증된 원자료를 사용했고 F6-H/F6-N 순위 상관은 0.8545로 계산됐다. 이전처럼 2E 성분 오차를 F6-H 전체 오차로 부르는 문제는 수정됐다.

그러나 컨센서스의 `asOf`가 없어 point-in-time 복원은 여전히 불완전하고, TSM·BABA·SPCX 및 비상장사의 기준·데이터 부족 문제가 남아 있다. 전용 밴드 `[27.8, 40.3, 58.4, 86.2, 125.1]`는 표본의 EPS 비율 1.3897을 기존 밴드에 곱한 후보일 뿐, 독립적인 시점 외 표본이나 예측 성능 기준으로 검증된 곡선이 아니다.

따라서 F6-H는 실험·보조 지표로는 의미가 있지만 정식 순위와 승인 점수에는 아직 포함하지 않는다. 추가로 point-in-time 자료, 기준 통일, 음수 EPS 처리 규칙, 외부 표본 검증이 확보되면 전용 밴드를 재평가한다.
