## C-12 — `v1.7` 파라미터 구조를 쓴다 (안2)

**비상장 F6 는 `P2` 가 점수를 내고 `P3`·`P4` 가 상한 1칸으로 보정한다.**

```
P2 = 밸류 ÷ TTM 보정 매출   →  v1.5 비상장 구간표 그대로
        ~20x → -2 · 20x대 → -3 · 30x+ → -4 · 100x+ → -5
P3 = ARR 증가율(직전 대비)  ┐
P4 = 자본효율 ARR ÷ 누적조달 ┘ 합쳐서 상한 1칸 보정 (상장 P4 와 같은 장치)
floor -5 · 천장 -2 (비상장은 0·-1 칸이 없다)
```

| | P2 배수 | P2 점수 | P3 | P4 | 보정 | **F6** |
|---|---|---|---|---|---|---|
| anthropic | ~30~39 | −4 | +38.3% | **0.52** | **+1** | **−3** |
| openai | ~39 | −4 | +60.0% | 0.22 | 0 | **−4** |

### 왜 안1(`P2` 만)이 아닌가

`v1.7` 은 비상장 트랙을 `parameters: ["P2","P3","P4"]` 로 선언한다. **안1 은 그 선언을 해 놓고 `P3`·`P4` 를 안 읽는다** — 오늘 `stale_asof` 에서 잡은 것과 같은 결함이고, `F6-FIX-21` 에서 **"소비자가 있는데 안 읽는 선언은 결함"** 으로 규칙까지 세웠다.

**더 근본적으로는 v1.5 가 규칙을 어긴 이유가 자본효율에 집이 없어서였다.** 3층 원칙 3차가 *"이익 환산치는 참고로 병기 — 점수엔 개입 없음"* 이라고 금지하는데도 `흑자 전환`과 `자본효율 0.52` 가 anthropic 을 한 칸 올렸다. **`v1.7` 이 P3·P4 로 그 집을 만든 것이고, 안1 은 집을 만들어 놓고 안 쓰는 선택이다.**

### 이 결정의 약점을 적어 둔다

**결과가 v1.5 발표 점수 `−3`·`−4` 와 정확히 같다.** `f6-band-decision.md` 에서 상장사 밴드를 정할 때 **"경계를 정한 근거가 표본이면 그 점수는 표본 밖에서 의미가 없다"** 고 적었는데, **여기서는 답을 먼저 알고 보정 방향을 정했다.**

완화 요소는 둘이다. `P2` 밴드는 v1.5 구간표라는 **외부 기준**을 그대로 쓰고 표본에서 뽑지 않았다. `상한 1칸 보정` 은 상장 `P4` 에서 이미 쓰는 장치라 새로 만든 것이 아니다. **그래도 보정이 어느 방향으로 갈지는 답을 보고 정한 셈이고, 그 사실을 숨기지 않는다.**

**기각한 안1 의 진짜 장점도 적어 둔다** — 표본 둘에서 아무것도 끌어오지 않고 전부 외부 기준만 쓴다. 자료가 `legacy_unverified` 이고 `arr` 은 ARR 이 아니라 런레이트이며 Series H 조달액이 원본 안에서 `$30B`·`$65B` 로 갈리는 상태에서, **"비상장 둘은 변별하지 않는다" 도 정직한 답이었다.**

## C-20 — G1 판정 보류 후 비상장 경로 (안B)

**단일 분기 영업흑자를 G1 통과 근거로 쓰지 않는다.** 동시에 **F9 를 영구 미완료로 두지도 않는다.**

```
비상장이고 TTM 영업손익이 구조적 미공시  →  G1 판정 보류(통과 아님)  →  G2 비상장 경로
    G2  g2_private_not_disclosed  -2
    G3  생략 (FCF 미공시라 소진율 없음)
    G4  같은 미공시 사유 중복 방지
    ──────────────────────────────────
    F9 = -2
```

**새 규칙을 만드는 것이 아니라 이미 있는 비상장 조항으로 보내는 것이다.** `g2_private_not_disclosed = -2` 는 `v1.5` 의 `미공시 보수 처리 원칙` 이고 openai 에도 같은 논리가 적용돼 있다.

**A(원칙 유지, 영구 미완료)를 기각한 이유** — F6 에 비상장 트랙이 있고 G2 에 비상장 조항이 있는데 **F9 만 영구 보류**로 두면 설계가 어긋난다.
**C(보수적 적자 간주)를 기각한 이유** — TTM 영업손익을 모르는데 적자라고 단정하는 것이고, **오늘 하루 종일 고친 것이 그런 단정이다.**

### 구현에 하나가 더 필요하다 — 엔진으로 확인했다

G1 을 넘겨도 지금은 G2 에서 멈춘다.

```
G2 result=pending   "TTM FCF 관측 not_disclosed/결측유형 미분류"
```

`anthropic.fcf_ttm` 이 `status: not_disclosed` 인데 **`missing_type` 이 안 붙어 있다.** `MISS-LABEL-23` 이 `_g2` 를 `missing_type == not_disclosed_confirmed` 로 바꿨는데 **재분류는 제안으로만 냈고 관측에 등록하지 않았다.**

**따라서 C-20 은 둘이 세트다.**

```
① G1 분기 추가    비상장 + TTM 영업손익 구조적 미공시 → 판정 보류하되 G2 비상장 경로로
② 관측 등록       anthropic.fcf_ttm 에 missing_type: not_disclosed_confirmed
                  근거는 worker 재분류 제안의 "비상장이라 공시 의무가 없다 — 구조적으로 확인된 미공시"
```
