## 다섯 지적

1. **산점도 점수가 검게 나오던 버그 (S1).** 원인은 `.c-g5{color:…}` 를 SVG `<tspan>` 에 단 것이었다.
   SVG 글자는 `color` 가 아니라 `fill` 로 칠해지므로 점수가 상속 기본값으로 떨어졌다.
   `svg .c-g5{fill:var(--g5)}` 계열 규칙을 따로 두어 고쳤고 출력 HTML 에 실린 것을 확인했다.
   두 SVG 의 글자 태그를 전수로 훑어 **색이 지정되지 않은 자리가 남지 않았다** — 색 미지정 13개는
   자식 tspan 이 각자 칠하는 묶음 태그이고 기업 수(알파벳·아마존 합침 13)와 맞는다.
2. **글자 크기 (S2).** 척도가 `12/13/14/16/22/26` 에서 `14/15/16/18/24/30` 으로 올라갔다.
   차트 안 하드코딩 `font-size` 도 12 에서 14~15 로 함께 올랐다. 표 셀·목록 여백도 같이 넓혔다.
3. **방법과 규칙의 C-XX (S3).** 한 덩어리 목록을 `method_block` 이 줄마다 독립 블록으로 뗐고,
   factor 표시를 제목으로 세운다(여러 factor 를 담은 줄은 세우지 않는다 — 잘못 읽히므로).
   `_decision_chips` 가 줄에 박힌 C-번호를 모아 `<details>` 로 그 자리에서 펼쳐 보게 한다.
   요약 문구는 `_decision_gist` 가 규칙 파일 `decisions[].summary` 의 첫 문장을 **잘라 오기만** 하고
   새로 쓰지 않는다. 펼치면 원문 전체와 이번 실행 선택이 나온다. `<details>` 라 터치에서도 된다.
4. **과점·함정 막대 (S4).** 0 기준 좌우 발산 막대를 산점도 옆에 **추가**했다(대체하지 않았다).
   좌우 축척을 하나로 묶은 것과, 폰 폭에서 글자가 줄지 않게 한 근거를 코드 주석에 남겼다.
5. **워커가 스스로 올린 것.** 방법 표 C-06 행의 마크다운 기호 노출을 `inline_html` 로 고쳤다.
