## 라운드1 진단 정정 — C-13 의 시뮬레이터는 엔진과 어긋나지 않았다

라운드1 검토에 **"둘 다 자기 시뮬레이터로 돌렸고 둘 다 출하 엔진과 어긋났다"** 고 적었다. **C-13 에 대해서는 틀렸다.**

초판 `3651c7b` 의 산출물을 다시 확인했다.

```
초판 f9_decision_simulation_results.json
  alibaba  {"score": null, "status": "pending_data"}    ← 엔진과 동일
  amazon   {"score": null, "status": "needs_judgment"}  ← 엔진과 동일

초판 verify_f9_independent.py test_06
  inputs = {"operating_result_reviewed": "profit", "coverage_comparable": "yes"}
                                          ↑ 두 입력을 이미 다 넣고 있었다
```

**C-13 의 코드와 데이터는 처음부터 맞았다.** 틀린 것은 그 위에 쓴 서술이다. 1절이 "C-16 이 alibaba 1개사의 점수를 직접 가른다" 로, 2절이 "C-16 은 alibaba 의 점수를 −2 와 −3 사이에서 직접 결정한다" 로 단정했는데, **자기가 방금 출력한 JSON 이 같은 칸에서 `pending_data` 라고 말하고 있었다.**

**이것은 시뮬레이터 결함이 아니라 이 프로젝트가 반복해 겪은 그 패턴이다.** C-13 R2-01 의 `comp.trade_cur` 상수, R2-02 의 `pass=False` 고정, R3-01 의 `trade_currency_status` 미연결이 전부 **계산해 놓고 안 쓰는** 형태였고, `F6-FIX-21` 검토에서 "소비자가 있는데 안 읽는 선언은 결함" 으로 규칙까지 세웠다. **이번은 그 결함이 코드가 아니라 보고서에서 났다 — 올바른 산출을 요약이 덮어썼다.**

NTM 은 성격이 다르다. `f9-simulation.json` 원본에 amazon 이 `"blocked_by": "C-16"` 으로 들어 있어 **시뮬레이터 자체가 `coverage_comparable` 게이트와 `parse_failed` 구분을 모델링하지 않았다.** 그쪽은 진짜로 엔진과 어긋났다.

**둘의 처방이 다르다.** NTM 은 시뮬레이터를 고쳐야 하고, C-13 은 **산출과 서술을 대조하는 절차**가 필요하다. 라운드1 의 "출하 엔진 호출 대조를 완료 조건에 넣는다" 는 NTM 에는 맞지만 C-13 에는 과녁이 빗나갔다. C-13 에게 필요한 완료 조건은 **"보고서의 모든 단정을 자기 산출물 JSON 과 대조했는가"** 다.

## 반영 확인

**1절.** "점수를 움직이는 규칙 조합은 C-06 + C-05 `diagnose_only` 1건뿐이며 C-16 은 현행 자료에서 0개사를 움직인다" 로 바뀌었다. `coverage_comparable` 분포(`yes` 1 · `no` 2 · `unknown` 11)와 alibaba 2대 입력, amazon `parse_failed` 격리가 전부 들어갔다.

**2절 C-16.** "현행 baseline 자료 기준 점수 변동 0개사" 를 앞에 두고 "입력 보완 후 영향 분석" 을 뒤로 분리했다. **순서가 맞다.** 지금 무엇이 사실이고 무엇이 조건부인지가 갈린다.

**미완료 기업 수.** 3개사 → **4개사**로 고치고 spacex-xai 를 첫째로 올렸다. NTM 이 찾은 정정을 참조 없이 자기 자료로 확인해 반영했다.

## 남은 것 하나 — 4절 표가 자기 JSON 과 어긋난다

4절 매트릭스에서 **alibaba 행만 네 칸이 `−2`·`−3` 으로 남아 있다.** 같은 파일의 `matrix_simulation` 은 네 조합 전부 `pending_data` 다. amazon 행은 `보류` 로 적었는데 **같은 `pending` 상태인 alibaba 는 점수로 적었다 — 한 표 안에서 처리가 다르다.**

각주 `*` 가 조건부임을 설명하지만, 표 머리글이 "C-05 와 C-16 의 조합에 따른 14개사 **실측 점수**" 라 **셀 값이 실측이라고 말하고 있다.** 다음 사람이 표만 보고 alibaba 를 −2 로 읽는다.

**alibaba 네 칸을 `보류(G1·G4 입력)` 로 바꾸고 조건부 −2/−3 은 비고로 옮기면 된다.** 한 줄이다.
