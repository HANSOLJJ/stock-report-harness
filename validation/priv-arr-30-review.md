# NTM `30B` — `pass`. **구간표를 찾았다**

- 대상. NTM `b0a2587`.

## 2자 대조의 결정적 차이

**NTM 은 규칙 문서의 비상장 구간표를 찾았고 C-13 은 못 찾았다.** 그리고 **두 기업 모두 재현 실패함을 기계로 확인**했다. 내가 따로 짚은 것과 같은 자리이고, **NTM 은 스스로 도달했다.**

`arr` 은 채점표에, 밴드는 규칙 문서에 있다. **같은 폴더 두 파일을 다 열었는가가 갈랐다.**

## 발견 둘 — 원본 자체의 모순

### 1. Series H 조달액이 `$30B` 와 `$65B` 로 갈린다

```
⑨적자깊이 절   "완충이 외부 조달뿐이다 — 순현금 자체 창출이 아니라 Series H $30B($965B 밸류)에 기댄다"
비상장 표      "| Anthropic | $965B (2026/5 Series H $65B) | $65B (7월) | 14.8x | -3 |"
```

**같은 문서 안에서 두 배 넘게 다르다.** 확인했다.

**이것이 내 옛 오류와 맞물린다.** `PRIV-ARR-17` 검토에서 내가 `arr = $65B` 를 **Series H 조달액이 잘못 들어간 것** 으로 추정했다가 철회했다. 원본에 `Series H $65B` 와 `ARR $65B` 가 **둘 다** 있으니 혼동할 소지가 실재했던 것이고, **동시에 같은 원본이 `$30B` 라고도 적는다.** 셋 중 무엇이 맞는지는 원본만으로 못 가른다.

`cumulative_raised` 가 `약 $125B(2021년~)` 라 조달액 하나가 두 배 틀려도 총계에 미치는 영향은 `28%` 다. **작지 않다.**

### 2. `openai` `arr` 시점이 `7월` 과 `8/20` 으로 갈린다

```
③ 가속도 절     "ARR이 2~4월 $25B에서 정체하다 7월 $40B로 MoM +20% 복귀"
⑧ 절            "연매출 $40B(7월) = 약 35배"
비상장 표       "$40B (8/20)"
⑨ 표            "런레이트 $40B+(8/20)"
```

**값은 같고 시점만 갈린다.** `7월` 두 번, `8/20` 두 번이다. C-13 은 `8/20` 을, 이 조사는 갈린다는 사실 자체를 적었다. **갈린다고 적는 쪽이 맞다.**

### 3. `자본효율 0.22` 는 범위 하단에서만 나온다

```
40 / 180 = 0.2222     40 / 185 = 0.2162     40 / 190 = 0.2105
```

**`약 $180~190B` 라는 범위의 상단에서는 `0.21` 이라 `0.22` 가 재현되지 않는다.** 원본이 `0.22` 를 적으면서 분모를 `180~190` 범위로 둔 것이 어긋난다.

**"충돌" 보다 정확한 표현은 "범위 전체에서 재현되지 않고 하단에서만 성립" 이다.** baseline 관측이 `185,000,000,000`(중간값)을 쓰는데 그것도 반올림하면 `0.22` 라 통과한다. **범위를 점추정으로 바꾼 시점에 이미 선택이 들어갔고 그 선택이 기록되지 않았다.**

## 그런데 구간표를 다시 읽으니 A 가 스스로 무너진다

```
| -2 | 29~42 | ~20x *(ARR 배수 — TTM 보정 필수)* |
```

**괄호가 비상장 열에 붙어 있고 "TTM 보정 필수" 라고 못박는다.** 원시 `밸류÷ARR`(14.8·21.3)에 그대로 적용하는 것은 **표 자신의 주석이 금지한다.**

그리고 3층 원칙 3차가 이렇게 말한다.

> **3차** | 마진이 산출된다 | 이익 환산치를 **참고로 병기**한다 — **점수엔 개입 없음**

| | TTM 보정 배수 | 구간표 | 이익·자본효율 개입 | **규칙이 내는 점수** | v1.5 실제 |

| anthropic | 30~39 | `30x+` → **−4** | **금지** | **−4** | **−3** |
| openai | ~39 | `30x+` → **−4** | **금지** | **−4** | −4 |

**v1.5 의 `anthropic −3` 은 3층 원칙 3차가 명시적으로 금지한 개입의 결과다.** `흑자 전환`과 `자본효율 0.52` 가 점수를 한 칸 올렸다.

**이것이 C-12 의 최종 형태다** — 규칙은 둘 다 `−4` 를 내는데 발표된 점수는 `−3`·`−4` 이고, 그 차이가 **규칙이 금지한 자리에서 나왔다.**

### C 가 그 어긋남을 푸는 자리다

**`v1.7` 은 v1.5 가 비공식 조정으로 밀어 넣던 신호에 정식 자리를 준다.**

```
P2 = 밸류÷ARR (TTM 보정)   →  v1.5 비상장 구간표 그대로
P3 = arr 증가율            →  v1.5 에 자리가 없던 것
P4 = 자본효율              →  v1.5 가 "보조 지표" 로만 두고 점수 개입을 금지했던 것
```

**v1.5 에서 자본효율이 규칙을 어기고 들어온 이유는 집이 없었기 때문이다.** `v1.7` 에서는 `P4` 가 집이다.

**다만 경고를 그대로 둔다.** P3·P4 밴드를 표본 둘에서 뽑으면 **원하는 순서가 나오게 맞추는 것**이 된다. `P2` 는 v1.5 구간표라는 외부 기준이 있지만 `P3`·`P4` 는 없다.
