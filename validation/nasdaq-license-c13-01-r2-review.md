# Nasdaq 라이선스 실제 문의 경로 재검토

- 대상 커밋: `44eac2d`
- 대상 보고서: `C-13/validation/nasdaq-license-c13-01/REPORT.md`
- 판정: 조사 완료, 라이선스 미확정

보고서는 api.nasdaq.com의 자동 수집 제한, Nasdaq Data Link ZACKS/EE·EEH와 GDA/DFRF의 공식 계약 경로, derived data·외부 배포·보관 조건, 5대 필수 문의 요건을 정리했다. 그러나 공식 웹폼을 통한 실제 문의 발송과 Nasdaq의 서면 회신은 수행되지 않았다. 따라서 자동 수집 허용, 12종목 요금, NTM 파생 데이터, HTML 외부 배포, 보관권은 모두 미확정이다.

현재는 무료 api.nasdaq.com 사용과 점수 등록을 보류한다. 다음 단계는 법인 담당자가 공식 Data Link Contact Sales 웹폼 또는 Nasdaq Global Data Products 문의 양식으로 실제 신청하고 회신·계약 문서를 증거로 보존하는 것이다.
