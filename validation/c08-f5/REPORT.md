# C08-F5-44 — 별표 G 와 별표 H 가 같은 관계를 다르게 분류한다

## 0. 결론

**먼저 짚으라고 하신 것부터. C-08 은 C-04·C-07 과 같이 이미 점수에 닿지 않는 건이다.** 다만 이유가 둘이고, 둘 다 확인했다.

1. **어떤 코드도 `C-08` 을 읽지 않는다.** `decision_choice()` 가 호출되는 결정은 `C-03·C-04·C-05·C-06·C-13·C-16·C-20` 뿐이다.
2. **`compute_f5()` 는 판단의 `A`·`H` 만 읽는다.** 분류를 다시 하지 않고 승계값을 그대로 쓴다. 14개사 전부 `carried_score` 다.
3. **그리고 OpenAI 의 `A=+2` 는 Oracle $300B 를 빼도 유지된다**(§4-3). 미결 설명의 "승계 A+2 는 다른 동맹 근거로 점수 무영향" 이 맞다.

**그러나 문서 모순은 실재하고, 미결 설명이 적은 것보다 하나 더 크다.** 별표 H 자체 표 안에서 **3문 답이 완전히 같은 두 관계가 반대 판정을 받는다**(§3-1). 이것이 이번 조사의 핵심이다.

## 1. 별표 G 원문 — ⑤ 점수 판정

규칙 md `L180~230`. 산식은 `⑤ = 3 + 동맹등급(A) + 적대등급(H)` 이다.

### 1-1. 동맹 등급 A (0 ~ +2)

| A | 기준 |
|---|---|
| **+2** | 지분이 걸린 동맹이 **복수**이거나, **경쟁사까지** 내 매대·공정·플랫폼에 편입했다 |
| **+1** | 의미 있는 상업 동맹이 있으나 소수이거나 한 방향이다 |
| **0** | 확인되는 독립 상업 동맹이 없다 — 공짜 사용자뿐이거나 **관계사뿐** |

**동맹으로 세지 않는 것 3종**(L196~199)

> - **조달 ≠ 동맹** — 돈 주고 사오는 관계는 아군이 아니다 (Apple의 칩 구매·Gemini 라이선스, Meta의 멀티벤더 구매). **판별은 별표 H의 3문**
> - **공짜 사용자 ≠ 동맹** — 파생모델 수·오픈웨이트 개발자·HF 사용자 1,800만은 생태계 지표지 상업적 약속이 아니다
> - **관계사 ≠ 독립 동맹** — 같은 지배주주 아래 회사는 동맹으로 세지 않는다 (Tesla의 유일한 아군이 SpaceX라 A=0)

### 1-2. 적대 등급 H (0 ~ −3)

| H | 유형 | 기준 |
|---|---|---|
| **0** | 최소 | 규제 조사·소송·시장 차단이 눈에 띄지 않는다 |
| **−1** | **비용형** | 벌금·개별 소송·규제 조사·시장 일부 차단. **사업 구조는 안 건드린다** |
| **−2** | **구조형** | (a) 주요 고객이 곧 경쟁자이거나, (b) 사업의 **정당성 자체**를 겨냥한 적대 |
| **−3** | **다발형** | 구조형 적대가 **복수 전선에서 동시 진행** + 최대 파트너와도 긴장 |

## 2. `OpenAI → Oracle $300B` — 같은 관계, 세 곳에서 세 판정

**미결 설명은 두 곳(별표 G vs 별표 H)의 충돌로 적었으나 실제로는 세 곳이고, 그중 둘이 정면으로 반대다.**

| # | 위치 | 문언 | 분류 |
|---|---|---|---|
| ① | **규칙 별표 G 판정표** L226 | `OpenAI │ **+2** │ **Oracle $300B**·Amazon $50B·SoftBank·DoD │ −3 │ … │ **2**` | **동맹 근거** |
| ② | **채점표 OpenAI 절** L759 | *"Stargate LLC 공동 지분(OpenAI 40%·Oracle $7B·SoftBank 40%·MGX)·Broadcom(Jalapeño 공동개발)이 아군 — **Oracle $300B 컴퓨트 계약 자체는 사는 쪽의 조달이라 동맹 근거가 아니다(별표 H)**"* | **조달 — 명시적 제외** |
| ③ | **규칙 별표 H 4칸 표** L276 | `OpenAI → MS·Oracle·NVIDIA │ ✅ │ 떠날 수 있음 │ **내가 못 떠남** │ **A+2** │ **−4**` | **동맹(A+2)** |

**①과 ③은 동맹으로 세고, ②는 조달이라며 명시적으로 뺀다.** 그리고 ②가 근거로 드는 것이 바로 **별표 H** 인데, 별표 H 자신(③)은 A+2 를 준다.

**②가 규칙에 맞다.** 별표 G 자신의 배제 규칙 3종 첫 줄이 *"조달 ≠ 동맹 — 돈 주고 사오는 관계는 아군이 아니다"* 이고, OpenAI 는 Oracle 에게 컴퓨트를 **사는 쪽**이다. 별표 H 전제도 *"파는 쪽에겐 고객이 동맹 후보이고, **사는 쪽에겐 공급자가 조달**"* 로 못 박는다.

**즉 별표 G 판정표의 OpenAI 행이 별표 G 자신의 배제 규칙을 위반한다.**

## 3. ★ 더 큰 모순 — 별표 H 4칸 표 안에서 같은 답이 반대 판정을 받는다

미결 설명에 없는 것이고 이번 조사에서 나왔다.

`L270~278` 의 4칸 표에서 두 행을 나란히 놓는다.

| 관계 | 2 연동 | 3 상대가 떠날 수 있나 | 4 내가 떠날 수 있나 | **⑤** | ⑧ |
|---|---|---|---|---|---|
| **NVIDIA ← 하이퍼스케일러** | ✅ | **떠날 수 있음**(자체 칩 개발 중) | 내가 못 떠남(매출 40%) | **불인정** | −3 |
| **OpenAI → MS·Oracle·NVIDIA** | ✅ | **떠날 수 있음** | **내가 못 떠남** | **A+2** | −4 |

**세 문항의 답이 완전히 같은데 ⑤ 판정이 `불인정` 과 `A+2` 로 갈린다.**

별표 H 3번 규칙은 이렇다.

> **3** │ 상대가 나를 떠날 수 있나 │ **떠날 수 있으면 ⑤ 동맹 제외** — 매출이 연동돼도 상대가 대체품을 만드는 중이면 아군이 아니라 미래의 적이다

**규칙대로면 OpenAI 행도 `불인정` 이어야 한다.** 그리고 별표 G 는 그 자리에 `+2` 를 적었고, 그 +2 가 승계돼 지금 openai F5 = 2 를 만든다.

**규칙이 스스로를 재현하지 못한다.** 별표 G 머리말이 *"아래 판정표가 14개사 현행 점수를 전부 재현한다"* 고, 별표 H 가 *"이 3문이 v1.5 현행 판정을 전부 재현한다"* 고 각각 적는데, **두 재현 주장이 OpenAI 에서 서로 어긋난다.**

## 4. `Bedrock·광고주 예시` 와 `3문/4문 참조 혼재`

### 4-1. Bedrock — 같은 관계가 세 곳에서 다르게 적힌다

| 위치 | 문언 | 3번 답 | 판정 |
|---|---|---|---|
| L248 4칸 | *느슨한 거래 — Amazon ← Bedrock 입점사* | (떠날 수 있음/내가 떠날 수 있음) | — |
| L277 4칸 | `Amazon → Bedrock 18사 │ ✅ │ **떠날 수 있음**(다른 매대) │ 떠날 수 있음(대체 모델) │ **A+2** │ −1` | **떠날 수 있음** | **A+2** |
| L287 3문 | `Amazon → Bedrock 18개사 입점 │ 재판매 권리 │ ✅ │ **가능하나 이탈 유인 낮음** │ **동맹**` | **가능하나 유인 낮음** | **동맹** |

**L277 은 "떠날 수 있음" 이라 적고도 A+2 를 준다** — §3 의 OpenAI 와 같은 위반이다. **L287 은 같은 관계의 3번 답을 "가능하나 이탈 유인 낮음" 으로 바꿔 적어** 규칙과의 충돌을 피한다.

**즉 L287 이 이미 정성 기준을 몰래 도입하고 있다.** 규칙 3번에는 "이탈 유인" 이라는 개념이 없다. 있는 것은 **가능/불가능 이진** 뿐이다.

같은 완화가 광고주·정부 행에도 있다.

| 관계 | 3번 답 | 판정 |
|---|---|---|
| Meta ← 광고주 | **가능하나 대안 약함** | 동맹 |
| SpaceX·Palantir ← 미 정부 | **어려움(대안 적음)** | 동맹 |
| Anthropic ↔ 3사 | **지분으로 묶임** | 동맹 |
| TSMC ← 고객 | **불가 — 팹을 못 짓는다** | 동맹 |
| NVIDIA ← 하이퍼스케일러 | **가능 — 자체 칩 개발 중** | **동맹 아님** |

**실제로 쓰이고 있는 기준은 이진이 아니라 3단계다** — `불가` · `가능하나 유인/대안 약함` · `가능하고 대체품을 만드는 중`. 앞의 둘이 동맹, 마지막만 불인정이다. **문서에 적힌 규칙만 이진이다.**

미결 권고 *"계약상 가능성과 실질 대체·이탈 유인을 구분하는 정성 기준 필요"* 가 정확히 이 자리를 가리킨다.

### 4-2. `3문/4문 참조 혼재` — 세 가지 표기가 돈다

| 위치 | 표기 |
|---|---|
| 별표 H 표제 L231 | **"조달과 동맹을 가르는 4문"** |
| 별표 G L197·L221 | **"판별은 별표 H의 3문"** |
| 별표 H 판정 순서 L268 | *"별표 H의 **1·2·3번**으로 ⑤를 먼저 정하고, 그다음 독립적으로 4번을 포함해 ⑧을 잰다. 4번은 ⑤ 판정에 개입하지 않는다"* |
| 체크리스트 20 L728 | *"별표 H **3문** — ①무엇을 주고받나 ②상대가 잘되면 내가 잘되나(필수) **③끊으면 누가 아픈가**"* |

**앞의 셋은 서로 모순이 아니다.** 문항은 4개이고 그중 ⑤ 판정에 쓰는 것이 3개라는 뜻이며, L268 이 이미 해소한다. **표기만 흔들린다.**

**그러나 체크리스트 20 은 다르다.** 3번을 **"끊으면 누가 아픈가"** 로 적는데, 별표 H 의 실제 3번은 **"상대가 나를 떠날 수 있나"** 다. **다른 질문이다** — "끊으면 누가 아픈가" 는 오히려 4번(⑧ 소관)에 가깝다. **체크리스트가 규칙을 잘못 요약하고 있다.**

## 5. `Q20 긴장` 의 정체

**체크리스트 20번**이다(규칙 md L728).

> | 20 | **조달을 동맹으로 셌나?** | 별표 H 3문 — ①무엇을 주고받나 ②상대가 잘되면 내가 잘되나(**필수**) ③끊으면 누가 아픈가. 사는 쪽에겐 공급자가 조달이다 |

- **21** — *"동맹이자 의존인 관계를 한쪽에서만 셌나, 또는 같은 속성을 양쪽에서 셌나?"*

## 7. 점수에 닿는가 — 닿지 않는다

### 7-1. 코드 경로

```
decision_choice() 가 호출되는 결정 = C-03 · C-04 · C-05 · C-06 · C-13 · C-16 · C-20
C-08 은 없음
```

`compute_f5()`(`calc_qual.py` L89~100)는 판단의 `A`·`H` 를 정수로 읽어 `rules.f5_formula(A, H)` 를 부를 뿐이다. **분류를 다시 하지 않는다.** F5 전용 계산기 파일도 없다.

### 7-2. 분류를 바로잡아도 A 는 안 내려간다

Oracle $300B 를 동맹 근거에서 빼면 openai 의 남는 근거는 이렇다.

| 출처 | 남는 동맹 근거 |
|---|---|
| 별표 G | Amazon $50B · SoftBank · DoD |
| 채점표 L759 | **Stargate LLC 공동 지분**(OpenAI 40%·Oracle $7B·SoftBank 40%·MGX) · **Broadcom**(Jalapeño 공동개발) |

A=+2 기준은 **"지분이 걸린 동맹이 복수"** 다. Stargate LLC 는 **지분 동맹**이고 SoftBank 40%·Oracle $7B 가 그 안에 있으며, Broadcom 은 **공동개발**(별표 H 1번의 동맹 후보 요건)이다. **지분이 걸린 동맹이 복수라는 조건이 Oracle $300B 없이도 선다.**

→ **A=+2 유지, F5 = 3+2−3 = 2 유지.**

### 7-3. 그래서 C-04·C-07 과 같은 부류다

**단, 같은 부류인 이유가 다르다.** C-04·C-07 이 *코드가 결정을 안 읽어서* 무영향이라면, C-08 은 **그에 더해 분류를 바로잡아도 등급이 안 바뀌어서** 무영향이다. **두 겹으로 무영향이다.**

## 8. 그렇다면 무엇이 남는가

**점수는 안 바뀌지만 문서는 틀린 채로 있다.** 남는 것은 셋이고, 셋 다 기록 문제다.

1. **별표 G 판정표 OpenAI 행이 별표 G 자신의 배제 규칙을 위반한다**(§2). 채점표 L759 가 이미 올바른 판정을 적어 두었으므로 **둘 중 하나를 고쳐 맞추면 된다.**

# 11. 확인 요청 답변 — A=+2 가 Stargate·Broadcom 만으로 서는가

검토(`msg_6caede430e56` §4)에서 **"§3 의 모순은 Oracle 만 빼는 것이 아니라 `MS·Oracle·NVIDIA` 관계 전체를 불인정으로 만들고, 그러면 남는 것이 Stargate 공동 지분·Broadcom 뿐인데 그 둘만으로 A=+2 가 서는가"** 를 물었다.

## 11-1. 먼저 — §7-2 는 그 질문을 다루지 않았다

**§7-2 를 가리켜 답할 수 없다.** 그 문단은 **Oracle $300B 하나만** 빼고 별표 G 가 나열한 나머지(`Amazon $50B·SoftBank·DoD`)를 **3번 규칙에 대보지 않은 채 그대로 남겨** A=+2 를 주장했다. **질문이 더 엄격하고 그쪽이 옳다.** 다시 했다.

## 11-2. 다만 전제가 하나 어긋난다 — 남는 것이 둘이 아니라 넷이다

채점표 OpenAI ⑤ 절(L758~765)이 실제로 드는 동맹 근거는 **넷**이다.

| # | 근거 | 성격 | 채점표 문언 |
|---|---|---|---|
| ① | **Stargate LLC 공동 지분** | **지분** | OpenAI 40%·Oracle $7B·SoftBank 40%·MGX |
| ② | **Broadcom** | **공동개발** | Jalapeño 공동개발 |
| ③ | **미 국방부 CDAO 계약** | 상업 계약 | *"정부 계약은 상업적 약속이므로 아군으로 인정(Palantir·SpaceX와 같은 잣대) · **4사 공통이라 ⑤ 변별력은 없다**"* |
| ④ | **Amazon $50B 투자** | **지분** | *"🆕 Amazon $50B 투자(3월 라운드, $35B는 IPO/AGI 조건부)**도 지분 동맹***" |

**④ Amazon $50B 가 빠져 있었다.** 채점표가 **명시적으로 "지분 동맹"** 이라고 적는다.

**그리고 ④는 §3 의 수정으로 제거되지 않는다.** 별표 H 4칸 표의 문제 행은 `OpenAI → MS·Oracle·NVIDIA` 즉 **컴퓨트를 사는 조달 묶음**이다. Amazon $50B 는 **받은 투자**이지 컴퓨트 조달이 아니므로 그 묶음에 포함되지 않는다. ①도 마찬가지로 조달이 아니라 공동 출자 법인이다.

## 11-3. 답 — **선다. 다만 조건부다**

별표 G 의 A=+2 기준은 이것이다.

> **+2** │ **지분이 걸린 동맹이 복수**이거나, 경쟁사까지 내 매대·공정·플랫폼에 편입했다

§3 수정 후 남는 근거를 기준표에 직접 댄다.

| 조건 | 판정 |
|---|---|
| 지분이 걸린 동맹이 **복수**인가 | **예 — ① Stargate LLC + ④ Amazon $50B 로 둘** |
| 경쟁사까지 편입했는가 | 아니오 |

→ **첫 조건이 서므로 `A=+2` 유지. `F5 = 3+2−3 = 2` 유지. 점수 무영향 확정.**

**그러나 질문이 적은 대로 "Stargate·Broadcom 뿐" 이었다면 답은 반대였다.** 지분 동맹이 Stargate **하나**뿐이고 Broadcom 은 공동개발이라 지분이 아니다. 그 경우 `+1`(*"의미 있는 상업 동맹이 있으나 소수이거나 한 방향이다"*)이 되어 **F5 = 3+1−3 = 1** 로 내려간다. **다리를 받치는 것은 Broadcom 이 아니라 Amazon $50B 다.**

## 11-4. ★ 그런데 그 다리를 체크리스트 19 가 겨눈다

`A=+2` 가 **받은 투자 하나에 걸려 있다**는 것이 새로 드러난 취약점이다. 그리고 규칙이 바로 그것을 검사한다.

> | **19** | **⑤에서 "받은 투자"를 곧바로 동맹 +2로 셌나?** | 아군 확보는 **능동태**다. 피투자 관계는 ⑦⑧에서도 세므로 **이중 계상 위험** — 별표 G의 A 기준으로 판정 |

별표 G 의 A 기준 머리말도 같은 말을 한다 — *"**동맹 등급 A — '아군 확보'는 능동태다. 받은 게 아니라 맺은 것을 센다.**"*

**Amazon $50B 는 OpenAI 가 받은 투자다.** 체크리스트 19 를 엄격히 적용해 ④를 빼면 지분 동맹이 ① 하나로 줄고 **A=+1 → F5 = 1** 이 된다.

### 그래서 정확한 답은 이렇다

| 적용 범위 | A | F5 | 점수 |
|---|---:|---:|---|
| 현행(아무것도 안 고침) | +2 | **2** | — |
| **C-08 단독 수정**(§3 대로 조달 묶음 불인정) | **+2** | **2** | **무영향** |
| C-08 + 체크리스트 19 함께 적용 | **+1** | **1** | **−1 영향** |

**C-08 만 놓고 보면 점수 무영향이 확정된다.** 이것이 물으신 것의 답이다.

**다만 무영향인 이유가 "동맹이 두텁기 때문" 이 아니라 "받은 투자 한 건이 남기 때문" 이다.** 그리고 그 한 건은 규칙 자신의 검사 항목(체크리스트 19)이 겨누는 바로 그 유형이다. **C-08 을 무영향으로 닫더라도 이 사실은 함께 기록돼야 한다** — 나중에 체크리스트 19 를 적용하는 과제가 오면 그때 F5 가 움직인다.

참고로 anthropic 의 `A=+2`(*"Amazon·Google·MS 3사 전원 투자+유통"*)도 받은 투자에 기대지만 **유통**이 함께 적혀 있어 능동 요소가 있다. **openai 의 ④는 투자 단독이다.**

## 11-5. 결정은 적지 않는다

체크리스트 19 를 적용할지, ④를 지분 동맹으로 유지할지는 설계·사용자 몫이다. 여기서는 **두 경로의 결과만** 적는다.

# 12. 마지막 확인 — `DoD + Stargate + Broadcom` 만 남으면 A 는 얼마인가

## 12-1. 답: **`+1`. `0` 은 도달하지 않는다**

세 근거를 별표 G A 기준표에 하나씩 댄다.

| 남는 근거 | 성격 | **지분인가** | 별표 H 1번 동맹 후보 요건 |
|---|---|---|---|
| **Stargate LLC 공동 지분** | OpenAI 40%·Oracle $7B·SoftBank 40%·MGX 공동 출자 | **예** | 지분 ✓ |
| **Broadcom** | Jalapeño **공동개발** | **아니오** | 공동개발 ✓ |
| **DoD CDAO** | 정부 계약(파는 쪽). *"아군으로 인정 · **4사 공통이라 ⑤ 변별력은 없다**"* | **아니오** | 상업적 약속 ✓ |

### +2 를 두 조건 모두에 대본다

| +2 조건 | 판정 |
|---|---|
| **지분이 걸린 동맹이 복수** | **불성립 — 지분은 Stargate 하나뿐이다.** Broadcom 은 공동개발, DoD 는 고객이라 둘 다 지분이 아니다 |
| **경쟁사까지 내 매대·공정·플랫폼에 편입** | **불성립** — OpenAI 는 경쟁사를 자기 플랫폼에 올리지 않는다. 이 조항은 Alphabet(경쟁사 Meta 에 TPU 판매)·Amazon(매대 18개사)·TSMC(NVIDIA 의 적들까지)를 위한 것이다 |

→ **`+2` 불성립.**

### 0 도 대본다 — 열어 두라고 하신 대로

> **0** │ 확인되는 독립 상업 동맹이 **없다** — 공짜 사용자뿐이거나 **관계사뿐**

**0 은 "없다" 를 요구한다.** 남는 셋 중 **Broadcom(공동개발)과 DoD(정부 계약)는 공짜 사용자도 관계사도 아니다.** 별표 H 1번이 공동개발을 동맹 후보로 명시하고, 채점표가 정부 계약을 *"상업적 약속이므로 아군으로 인정(Palantir·SpaceX와 같은 잣대)"* 로 적는다.

**Stargate 를 관계사로 보아 빼더라도**(OpenAI 가 40% 를 쥔 공동 출자 법인이라 "내 아군" 으로 세는 것이 순환이라는 해석이 가능하다) **Broadcom 과 DoD 가 남으므로 0 은 성립하지 않는다.**

→ **`0` 불성립. 답은 `+1` 이다.**

`F5 = 3 + 1 − 3 = **1**`, openai 총점 `3 → 2`. §11-4 의 계산과 같다.

## 12-2. ★ 다만 "한 행의 결함" 은 성립하지 않는다

검토 §2 가 A=+2 를 **다섯**으로 훑고 *"+2 다섯 중 OpenAI 만 근거가 수동태"* 라고 적었다. **별표 G 판정표의 +2 행은 여섯이다. `Anthropic` 이 빠졌다.**

| 기업 | A | 별표 G 동맹 근거 | 능동/수동 |
|---|---|---|---|
| **Anthropic** | **+2** | **Amazon·Google·MS 3사 전원 _투자_+유통** | **투자 = 받은 것(수동)** |
| Alphabet | +2 | 경쟁사 Meta 에까지 TPU 판매 · Anthropic 5GW | 파는 쪽(능동) |
| Amazon | +2 | 매대 18개사 · Anthropic $25B 투자 | 주는 쪽(능동) |
| Microsoft | +2 | OpenAI 27% + Anthropic $30B 양다리 | 주는 쪽(능동) |
| TSMC | +2 | 고객 전부 아군 | 파는 쪽(능동) |
| OpenAI | +2 | Oracle $300B·Amazon $50B·SoftBank·DoD | 넷 중 셋 수동 |

**Anthropic 의 `+2` 도 받은 투자에 기대고 있다.** 체크리스트 19 를 일관되게 적용하면 Anthropic 에서도 `투자` 가 빠지고 **`유통` 만 남는다.**

그러면 Anthropic 도 같은 시험에 걸린다.

| +2 조건 | Anthropic(투자 제외 시) |
|---|---|
| 지분이 걸린 동맹이 복수 | **불성립** — 유통은 지분이 아니다 |
| 경쟁사까지 내 매대·공정·플랫폼에 편입 | **불성립** — 방향이 반대다. Anthropic 이 3사 **플랫폼에 올라간** 것이지 3사를 자기 플랫폼에 편입한 것이 아니다 |

→ **Anthropic 도 `+1`, `F5 = 3+1+0 = 4`(현행 5에서 −1).**

### 그래서 성격을 다시 적어야 한다

| 적용 | openai | anthropic |
|---|---|---|
| 현행 | F5 **2** | F5 **5** |
| C-08 단독 | F5 2 (무영향) | F5 5 (무영향) |
| **C-08 + 체크리스트 19** | F5 **1** | F5 **4** |

**체크리스트 19 는 한 행이 아니라 두 행을 움직인다.** 검토 §2 의 *"일반화되는 결함이 아니라 한 행의 결함이고 그래서 더 선명하다"* 는 **Anthropic 을 빼고 센 결과**다.

**다만 §3 의 Apple 행 증거는 그대로 선다.** 그것은 **조달 배제**(별표 H)의 불일치이고 Anthropic 과 무관하다. 조달 배제는 OpenAI 한 행의 결함이 맞고, **받은 투자**(체크리스트 19)는 두 행에 걸친다. **두 결함을 갈라서 올려야 한다.**

## 12-3. 사용자께 올릴 때 갈라야 할 둘

# 13. A/B 분리 채택에 붙이는 단서 — **A 의 적용 범위는 해석에 달려 있다**

검토가 *"A(조달 배제)는 OpenAI 만 잡고 Anthropic 은 못 잡는다"* 로 정리했다. **그 정리는 §4-1 의 3단계 해석을 전제할 때만 성립한다.** 문서에 적힌 이진 규칙을 문자대로 적용하면 A 의 범위가 훨씬 넓다.

## 13-1. 별표 H 3번의 문언은 이진이다

> **3** │ 상대가 나를 떠날 수 있나 │ **떠날 수 있으면 ⑤ 동맹 제외**

**"가능" 이면 제외**다. 정도를 따지는 조항이 없다.

## 13-2. 그 문언대로 3문표 전 행에 적용하면

| 관계 | 3번 답 | 문서상 판정 | **이진 규칙대로면** |
|---|---|---|---|
| TSMC ← 고객 전부 | **불가** — 팹을 못 짓는다 | 동맹 | 동맹 ✓ |
| Apple ← App Store 개발자 | **불가**(iOS 유일 채널) | 동맹 | 동맹 ✓ |
| Amazon → Bedrock 18개사 | **가능**하나 이탈 유인 낮음 | 동맹 | **제외** |
| Anthropic ↔ Amazon·Google·MS | 지분으로 묶임 / *4칸표는* **가능**하나 지분으로 묶임 | 동맹 | **제외** |
| SpaceX·Palantir ← 미 정부 | **어려움**(대안 적음) | 동맹 | **제외** |
| Meta ← 광고주 | **가능**하나 대안 약함 | 동맹 | **제외** |
| NVIDIA ← 하이퍼스케일러 | **가능** — 자체 칩 개발 중 | 동맹 아님 | 제외 ✓ |

**`불가` 인 두 행만 살아남는다.** 나머지는 표현만 다를 뿐 전부 "가능" 계열이다.

## 13-3. 그러면 A 가 다섯 회사로 번진다

| 회사 | 별표 G 동맹 근거 | 이진 규칙 적용 시 |
|---|---|---|
| amazon | 매대 18개사(**Bedrock**) · Anthropic $25B | Bedrock 제외 → 지분 1개 → **+1**(4→3) |
| **anthropic** | 3사 전원 투자+**유통** | 유통 제외 → **A 가 Anthropic 도 잡는다** |
| meta | **수백만 광고주 생태계** | 유일 근거 제외 → **0 위험**(3→2 이하) |
| spacex-xai | **NASA·Space Force·DoD** | 유일 근거 제외 → **0 위험** |
| palantir | **미 정부**·NVIDIA·SAP·Accenture | 정부 제외 → 나머지 미평가 |

**이 번짐이 비상식적이라는 것이 오히려 3단계가 실제 규칙이라는 증거다.** v1.5 저자가 이진 규칙을 적어 놓고 실제로는 3단계로 판정했고, 그래서 14개사 현행 점수가 나왔다.

## 13-4. ★ Anthropic 은 두 표의 표현이 갈려서 결정된다

검토가 인용한 *"지분으로 묶임"* 은 **3문표**(L290)의 표현이다. **4칸표**(L273)는 같은 관계를 **"가능하나 지분으로 묶임"** 으로 적는다.

```
3문표  Anthropic ↔ Amazon·Google·MS │ 지분 + 유통 │ ✅ │ 지분으로 묶임        │ 동맹
4칸표  Anthropic → 3사              │      ✅     │ 가능하나 지분으로 묶임 │ A+2 │ -3
```

**`가능하나` 네 글자가 있고 없고가 A 의 Anthropic 포획 여부를 가른다.** 3문표 표현이면 안 걸리고 4칸표 표현이면 걸린다. **같은 관계, 같은 문서, 두 표현** — §4-1 의 Bedrock 과 정확히 같은 형태다.

## 13-5. 그래서 올릴 때 함께 물어야 할 것

A/B 분리는 그대로 맞다. 다만 **A 를 올릴 때 "별표 H 3번을 어느 해석으로 적용하는가" 를 같이 물어야 한다.**

| 3번 해석 | A 가 잡는 범위 | anthropic |
|---|---|---|
| **3단계**(실제 판정 관행) | **OpenAI 한 행** | **안 걸림** |
| **이진**(문서 문언) | OpenAI·amazon·anthropic·meta·spacex·palantir | **걸림** |

**해석을 정하지 않으면 A 의 범위가 정해지지 않는다.** 그리고 그 해석 자체가 §4-1·§8-2 가 남긴 과제다 — *"이미 암묵적으로 쓰이고 있는 3단계를 적어 내는 일"*.

**B(체크리스트 19)는 해석에 안 흔들린다.** 능동태냐만 묻고 이탈 가능성을 묻지 않으므로 **어느 해석에서도 OpenAI·Anthropic 둘을 잡는다.** 검토의 그 판단은 그대로 맞다.

**결정은 적지 않는다.**
