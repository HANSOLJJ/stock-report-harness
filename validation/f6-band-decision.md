- 결정자. 사용자.

## 확정 밴드

```
P1  PER          25 / 45          (-2 ~ 0)
P2  EV/Sales      8 / 20          (-2 ~ 0)
P3  성장률       30% / 15% / 5%   (-3 ~ 0)
P4  입력 신뢰도   보정 상한 1칸
경계 허용오차    ±3% 표시 (현행 F6 boundary_tolerance 유지)
```

**반개방 구간이다.** P1·P2 는 `upper 미만`, P3 는 `이상`이다.

| P1 PER | 점수 | P2 EV/Sales | 점수 | P3 성장률 | 점수 |
|---|---|---|---|---|---|
| < 25 | 0 | < 8 | 0 | ≥ 30% | 0 |
| 25 ~ 45 | −1 | 8 ~ 20 | −1 | 15 ~ 30% | −1 |
| ≥ 45 | −2 | ≥ 20 | −2 | 5 ~ 15% | −2 |
| | | | | < 5% | −3 |

## 근거 — 통상 시장 기준

**표본에서 뽑지 않았다.** 각 경계가 시장 통념의 기준선이다.

| 경계 | 통상 의미 |
|---|---|
| **PER 25** | 고평가 논쟁이 시작되는 지점 |
| **PER 45** | 40배+ = 고성장 전제가 있어야 정당화되는 구간 |
| **EV/Sales 8** | 소프트웨어·고마진 정상 구간(5~10)의 중간 |
| **EV/Sales 20** | 버블 논쟁선 |
| **성장 30%** | 초고성장 |
| **성장 15%** | 고성장 하한 |
| **성장 5%** | 정체 경계 |

이 프로젝트는 F6-H 때 **표본 EPS 비율(1.3897)을 기존 밴드에 곱해 만든 밴드**를 "독립 검증 안 됨" 으로 반려한 전례가 있다. **경계를 정한 근거가 표본이면 그 점수는 표본 밖에서 의미가 없다.** 통상 기준을 쓰면 그 문제가 없다.

`v1.5` 의 기존 밴드도 같은 성격이다 — `20·29·42·62·90` 은 시작점 20 에 배수 1.46 을 곱해 만든 것이지 표본에서 뽑은 것이 아니다.

**설계 의도가 작동한다.**

- **tesla −5** — PER 370배에 성장 11.8%. **비싸고 안 크는** 밸류에이션 함정의 전형
- **palantir −4** — PER 144배지만 성장 78.9%라 P3 가 0. tesla 보다 한 칸 낫다
- **oracle·apple −4** — PER 은 무난한데 **성장이 느려서** 내려앉았다
- **nvidia −2** — 밸류에이션이 높지만 성장 83% 가 상쇄

**단일 PER 이었다면 tesla 와 palantir 가 갈리지 않았다.** P3 에 −3 을 준 것이 판정을 가른다.

### 자본구조 반영 사례

`EV/시총` 이 대부분 0.97~1.05 인데 **oracle 만 1.305** 다. 순차입 $135.5B 때문에 P/S 6.6 이 EV/Sales **8.6** 으로 올라간다. **meta 와 P/S 가 6.6 으로 같은데 EV 기준으로는 oracle 이 30% 비싸다.** P2 분모를 EV 로 둔 것이 여기서 값을 한다.

### 통화 결정이 한 칸을 가른 사례

**alibaba 는 현지통화로 +2.7%(−3)이고 공시 USD 로는 +8.1%(−2)다.** `F6-FX-16` 의 "P3 는 현지통화" 결정이 실제로 밴드 한 칸을 결정한다.

## 검토한 대안과 기각 사유

사용자가 **"+30% 가 만점이면 상단 변별이 없다"** 고 지적했다. 실측에서 nvidia +83.4% 와 palantir +78.9% 가 tsmc +33.9% 와 같은 0점을 받는다.

지적은 타당하나 **밴드 상향으로는 풀리지 않는다.**

| 경계 | 분포 | 문제 |
|---|---|---|
| **30/15/5** | 0:3 · −1:4 · −2:3 · −3:1 | 채택 |
| 50/25/10 | 0:2 · −1:2 · **−2:6** · −3:1 | 6개 뭉침 |
| 60/30/15 | 0:2 · −1:1 · −2:4 · **−3:4** | 대부분 하위로 밀림 |
| 40/20/8 | 0:2 · −1:3 · **−2:5** · −3:1 | 5개 뭉침 |

**실측 분포가 세 덩어리다.** 80%대 둘, 12~34% 사이 일곱, 3% 하나. 중간 덩어리를 어디서 자르든 임의적이고, **기준을 올릴수록 그 일곱이 한 칸에 뭉쳐 변별이 나빠진다.**

그리고 상단 변별은 구조적으로 F6 의 일이 아니다. **F6 는 함정 factor 라 천장이 0 이고 "잘함" 을 표현할 수단이 없다.** nvidia 의 83% 성장은 과점 쪽에서 인정받을 일이고, 실제로 **③ LastMover 가 가속도로 재고 있다.**

## 0점이 없다는 것

현재 밴드에서 **F6 0점을 받는 기업이 하나도 없다.** 범위가 −1 ~ −5 로 −7 중 5칸만 쓴다.

사용자가 이를 확인하고 **그대로 확정**하기로 했다. **이 유니버스가 통째로 비싸다는 것이 결론**이며, 기준을 완화해 0점을 만들면 "비싸지 않다" 는 판정을 인위적으로 만드는 셈이 된다.
