# NASDAQ-LICENSE-C13-01 재검토

- 검토 대상: C-13 커밋 `c9dc909`
- 판정: `pass`

## 결정

- 무료 `api.nasdaq.com`는 생산 수집·자동화·공개 배포에 사용하지 않는다.
- 정식 문의는 `datasales@nasdaq.com`과 `DataOps@nasdaq.com` 경로로 진행할 수 있으나, 사용자가 법인 정보와 외부 배포 범위를 확정하고 승인하기 전에는 발송하지 않는다.
- 애널리스트 추정치 상품이 GDA인지 Data Link/Zacks 별도 상품인지, 공개 HTML의 파생 데이터 배포가 허용되는지는 Nasdaq의 서면 답변 전까지 미확인으로 유지한다.
- 계약·배포 조건이 확인되기 전에는 Nasdaq 관측을 scorecard 입력으로 등록하지 않는다.

보고서의 Zacks 상품·요금·보존 조건 서술은 공식 회신 전 잠정 정보로 취급한다.
