### 임계값을 정한다 — **보고 주기에 상대적으로**

실측 분포를 뽑았다.

```
tsmc       annual  2025-12-31   8.0개월
alibaba    annual  2026-03-31   5.1개월
oracle     ttm     2026-05-31   3.1개월
… (TTM 9개사)                   1.2 ~ 3.1개월
```

**단일 임계값은 안 된다.** `6개월` 로 두면 **모든 연간 신고자가 상시 걸려** `period_basis_not_ttm` 과 중복되고, 내가 `G1-TTM-26` 에서 금지한 **"FPI 라는 사실 하나로 두 번 깎기"** 가 된다. `16개월` 로 두면 **분기 신고자가 10개월 묵어도 안 걸린다.**

```
stale_asof
  period_basis = ttm / quarterly   →  창 종료일이 기준일로부터  6개월 초과
  period_basis = annual            →  창 종료일이 기준일로부터 16개월 초과
```

**근거.** 연간 `16 = 12(주기) + 4(20-F 제출 기한)`. 다음 회계연도가 닫히고 제출될 때까지 최신 FY 가 자연히 나이 드는 최대치다. 그 밖은 **제출 지연이나 수집 공백**이다. 분기 `6 = 3(주기) + 여유`.

**현재 12개사 전부 통과하고, 오늘 아침의 TSM(20.1개월)은 걸린다.** 조건이 잡으려던 것을 정확히 잡는다.
