- 판정: `pass`

## 확인

- SpaceX와 xAI가 합병 후 단일 법인 연결 범위라는 정정과 실제 레코드 수 19개 관측·8개 판단 정정을 승인한다.
- SPCX가 상장 보통주임에도 Finnhub 심볼 지정 조회가 0건인 사실을 확인했다.
- 기존 승인 실행의 해시·HTML을 보존한 판단을 승인한다.

## 결정

1. 이력 연결은 중앙 별칭 해석 계층을 둔다. 과거 `spacex-xai`를 삭제하거나 history.csv를 재작성하지 않고 새 정규 기업 ID `spacex` 조회 시 과거 별칭을 연결한다.
2. SPCX 분기 EPS 원천은 별도 조사로 찾는다. Finnhub과 무료 FMP는 채택하지 않으며, 새 원천의 실제 응답·회계기간·basis를 확인하기 전 F6에 사용하지 않는다.
3. TTM 창이 합병 전 기간을 포함하면 소급 연결 근거가 있는 공식 재작성 수치만 사용한다. 근거가 없으면 해당 TTM 관측은 `pending_data`로 보류하고 합병일 이후 기간만으로 임의 대체하지 않는다.
4. 기준선 주가·시가총액은 SPCX 단독 원천으로 재검증한다. 검증 전 legacy 값을 F6 입력으로 승격하지 않는다.
