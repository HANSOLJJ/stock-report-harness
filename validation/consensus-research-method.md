# 전망치 원천 조사 공통 방법과 업무 분담

2026-09-09 사용자 지시를 반영한다. Valley 화면에서 확인한 자료 구성과 검증 방법을 다른 원천 조사에 적용한다. Valley의 기업별 링크 확보나 Valley 단독 수집을 선행 조건으로 삼지 않는다. 기존 NTM 4분기 규칙을 변경하거나 점수를 수정하는 작업이 아니다.

## Valley에서 확인한 방법

사용자가 제공한 NVIDIA 종합 전망 화면에는 회계분기별로 지표를 나누고, 각 지표의 최솟값·평균·중간값·최댓값·전망치 수를 표시한다. 실제 발표값과 예상값(E), 일반 EPS와 GAAP EPS 행을 구분하며 단위 안내를 제공한다. 이 구조를 다른 원천 조사에 적용한다. Valley의 실제 데이터 공급사, 상세 집계·제외 규칙은 아직 확인하지 않았으므로 추측하지 않는다.

- 기본 관측 단위는 기업 × 회계분기 × 지표 × 원천 × 추정 시점이다.
- 같은 분기의 평균·중간값·최소·최대·전망치 수를 구분해 저장한다. 전망치 수는 해당 지표·분기의 표본 수이며 전체 기업 커버 애널리스트 수와 같다고 가정하지 않는다.
- 최소·최대는 관측된 전망 범위다. 확률 구간이나 실적의 보장 범위로 해석하지 않는다.
- 평균값이 있으면 기본 EPS 합산 후보로 사용한다. 중간값을 평균으로 바꾸어 부르거나, 평균·중간값을 분기마다 임의 혼합하지 않는다.
- 통계 항목 일부가 없으면 결측으로 기록한다. 최소·최대·표본 수 미제공만으로 확보된 EPS 평균 자체를 폐기하지 않는다. 필수 채점 입력의 결측과 보조 정보의 결측을 분리한다.

참고 페이지는 https://www.valley.town/financials/quote/NVDA:US/expert-forecast/total?period=Interim 이다. 로그인 후 NVIDIA 일반 EPS 행에서 FY2027Q3/Q4, FY2028Q1/Q2의 표시 평균 2.47/2.74/3.20/3.67, 표본 수 44/42/40/40을 확인했다. 표시값 합은 12.08이다. 이는 분기 수치 확보 사례이며 자동 채점 적격성 검증 완료나 과거 기준선에 반영 가능한 시점 자료라는 의미가 아니다. 화면의 분기 종료일은 공급사 라벨로 보존하고 회사 공식 회계기간과 별도 대조한다.

## 상장사 조사 순서

1. 기존 조사에서 확보한 자료와 결측을 먼저 읽는다. 이미 확인한 정적 경로를 같은 방식으로 반복하는 대신 미조사 원천·동적 화면·공식 정의를 조사한다.
2. 기준시각과 직전 발표 실적을 확인해 다음 4개 미발표 회계분기 창을 정한다. 끝난 분기도 실적 미발표이면 포함될 수 있다. 모든 기업의 분기를 3·6·9·12월로 맞추지 않는다.
3. 다른 금융정보 서비스와 공급사 공식 자료에서 해당 기업·분기 EPS 컨센서스 표를 찾는다. 기업 IR은 기간·실적 발표·주식단위 등의 근거로 사용하고 경영진 가이던스를 애널리스트 컨센서스로 취급하지 않는다.
4. 가능하면 한 원천에서 4분기 전체를 수집한다. 서로 다른 공급사의 일부 분기를 이어 붙여 검증된 NTM으로 만들지 않는다. 원천별 후보 묶음을 별도로 보존한다.
5. URL, 조회 시각, 공급사의 갱신/추정 기준 시각(미표시면 미확인), 원문 스냅샷, 통화, 보통주/ADR/ADS, 희석·기본 EPS, 분할·GAAP/조정 기준을 기록한다. 조회 시각이 추정치 갱신 시각을 증명하지는 않는다.
6. 자료 확보(0/4~4/4), 기준 검증, 채점 적격성을 분리한다. EPS가 0 또는 음수여도 유효 관측으로 보존한다. 네 분기 합이 0 이하일 때의 채점 보류를 자료 미확보로 바꾸지 않는다.
7. 4분기 평균 EPS 합과 같은 기준의 주가로 계산 후보를 만들되, 기준 미확인 값은 검증 대기로 표시한다. 현재 자료를 2026-09-02 기준선에 소급 적용하지 않는다. EPS 평균에 전망치 수를 다시 가중해 분기간 합산하지 않는다.
8. 원천별 접근 조건(공개/로그인/구독), 실제 성공·실패 경로, 반복 수집 방법과 한계를 기록한다. 결제·가입이 필요하면 해당 경로를 보류하고 다른 원천을 계속 조사한다. 미조사를 부재·불가능으로 단정하지 않는다.

## 업무 분담

| 담당 | 대상 | 범위 |
|---|---|---|
| NTM-전망치조사 | Meta, NVIDIA, Alphabet, Microsoft, Amazon, Apple, Oracle, Palantir, Tesla, SpaceX | 상장 여부를 기준시점에서 확인하고 위 방법으로 4분기 EPS와 대체 원천 조사 |
| C-13 | TSMC, Alibaba | 같은 조사. TSM/2330, BABA/9988의 통화·보통주/ADR/ADS 환산 기준을 특히 검증 |
| C-13 | OpenAI, Anthropic | 비상장 자료 별도 조사. 최근 투자 후 기업가치, 실제 연간·TTM 매출, ARR/연율화 매출, 매출 전망, 누적 투자유치액의 원천·시점·정의를 구분 |

비상장사는 공시·공식 발표·투자자 발표·원문 근거가 있는 보도를 대조한다. ARR, 연율화 매출, 실제 12개월 매출은 서로 다른 값이다. 투자 후 기업가치와 다른 거래가치, 확정 조달액과 조달 계획도 구분한다. 기업별 주식거래 가능성과 상장 여부는 기준시점에서 확인한다. 비상장사에 NTM EPS 4분기나 상장사 PER 점수를 억지로 적용하지 않는다. 공개되지 않은 값은 미확보로 남긴다.

## 공통 산출물과 완료 보고

각 worktree의 새 `validation/consensus-source-2026-09-09/` 디렉터리에 `REPORT.md`, `evidence.json`, 원문 스냅샷, 필요한 검증 스크립트와 실행 결과를 남긴다. 기존 보고서·원문을 덮어쓰거나 삭제하지 않는다. worker의 코드·점수 입력·승인·규칙은 읽기 전용이다.

보고 표는 기업, 지표, 기간, 값과 통계 종류, 전망치 수, 단위/회계 기준, 원천 URL, 관측/추정 시각, 접근 조건, 확보 수준, 부족 정보, 채점 사용 가능 여부를 포함한다. 비상장사에 해당하지 않는 통계는 해당 없음으로 둔다. 출처가 다른 충돌값은 나란히 보존한다.

공통 원천 발견 시 상대 팀에 자료 구성과 재현 경로를 공유한다. 상대에게 추가 실행을 요청하는 경우 메시지와 터미널 실행 안내를 함께 보낸다. 로그인 정보나 세션 토큰을 보고서·메시지·git에 저장하지 않는다.

수신 즉시 원 요청 메시지에 수신 확인을 회신한다. 완료 시 담당 기업별 확보·미확보·미검증 수, 새 원천, 검증 결과, 커밋과 파일 경로를 같은 스레드에 회신한다. 결과의 사실 검증과 최종 채점 정책 결정은 구분한다.

기존 참고 자료는 설계진행 `validation/data-availability-2026-09-08.md`, scarpper `validation/qwen-ntm-data-03/REPORT.md` 및 정정 증거, C-13 `validation/c13-data-01/REPORT.md` R8, worker `docs/scorecard/design-guideline.md`다. 철회된 N-04/N-06/N-07 추론을 재사용하지 않는다.
