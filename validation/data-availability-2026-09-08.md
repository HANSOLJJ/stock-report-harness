# AI 9-factor 자료 확보 현황

작성일은 2026-09-08이다. 이번 표는 기존 조사 산출물을 합친 기록이며, 작성 시점에 웹을 다시 조회한 결과가 아니다. 조사 집중 범위는 상장사 F6의 NTM PER 입력이다. 전체 9개 factor의 최신 자료 수집 완료를 의미하지 않는다.

## 확보 여부와 채점 가능 여부

| 자료 | 확보한 것 | 부족하거나 미검증인 것 | 현재 사용 가능 범위 |
|---|---|---|---|
| 주가·공급사 Forward PE | 두 조사에서 수치와 원문 스냅샷 수집 | 각 값의 기준일 일치 및 Forward PE 분모의 공식 기간 정의 | 조사 참고값. 필드 이름만으로 NTM 적격 판정 불가 |
| 향후 분기 EPS 컨센서스 | 조사 대상 상장사 12개 모두 기업별 2개 분기 관측 | 다음 4개 미발표 회계분기 중 나머지 2개 | 일부확보. 4분기 합산 NTM EPS 계산 불가 |
| 연간 EPS 컨센서스 | 연간 전망 수치 관측 | 다음 4개 미발표 분기의 합과 같은 계산이라는 근거 | 참고값. 자동으로 NTM 분모로 대체 불가 |
| EPS 입력 메타데이터 | 분기 라벨 및 일부 통화·회계 기준 | 기업·원천별 추정치 시점, GAAP/조정 기준, 주식·ADR/ADS 기준 등 계약 충족 확인 | 통화·주식단위 등이 맞아야 주가와 나눗셈 가능 |
| 기존 기준선 점수 | 기존 입력을 framework로 이관하고 계산한 결과 | 이번 조사 자료로 모든 입력을 교체한 최신 점수 | 역사적 기준선 재계산 결과로 표시 |
| F1–F5·F7–F9 최신성 | 기준선 입력·기존 판단 및 구현 검증 기록 | 이번 NTM 조사로 이 factor들의 최신 자료까지 검증한 것은 아님 | 최신 재조사 완료 표시 금지 |

4분기 자료를 모두 확보한 기업은 현재 조사 결과에서 0개다. 0 또는 음수인 개별 분기 EPS도 확보한 자료로 인정한다. 네 분기의 합이 0 이하인 경우의 채점 보류는 자료 미확보와 별개다.

## 해석 및 화면 표시 지침

- 기존 HTML 점수는 기존 기준선 입력을 framework 규칙으로 계산한 결과다. 이번 조사에서 새로 수집한 4분기 EPS로 재산출한 점수라고 표시하지 않는다.
- 기존 `vendor_forward_pe_verified_ntm` 명칭은 이관 코드의 문자열이며, 최신 NTM 검증 완료 근거가 아니다. 기존 `ntm_per` 12건의 상태는 조사 당시 `legacy_unverified`였다.
- scarpper 10개사의 공급사 Forward PE 기간은 `period_unknown`, NTM 적격성은 `unverified`다. NTM이 아님을 증명한 것도 아니다.
- 회계연도 말일까지 12개월 미만이라는 이유만으로 NTM 불가라고 판정하지 않는다. 철회된 N-04·N-06·N-07 추론을 재사용하지 않는다. JSON의 과거 요약 문구보다 정정된 기업별 판정과 최종 검토 기록을 우선한다.
- 자료 현황과 실제 채점에 반영된 입력을 별도 항목으로 보여준다. 조사일, 관측 기준일, 원천, 부족 자료, 채점 반영 여부를 확인할 수 있게 한다.
- C-번호는 코드만 노출하지 않고 제목·의미·현재 결정·영향을 클릭해 펼칠 수 있게 한다. 미결 정책을 UI 변경 과정에서 임의 확정하지 않는다.
