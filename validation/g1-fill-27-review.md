# G1-FILL-27 재검토 — 상장 12개사 TTM 매출·영업손익

- 검토일. 2026-09-11.
- 대상. C-13 `3260f24`. **NTM `27B` 는 아직 미도착이라 2자 대조는 뒤로 미룬다.**
- 판정. **`needs_fix`.** **9개사 수치는 내가 독립 복원해 한 자리도 안 틀렸다.** 그러나 **SPCX 분류가 틀렸고 반증이 C-13 자신의 커밋 안에 있다.**

## 독립 재현 — 9/9 정확

두 보고서를 정답으로 쓰지 않고 `companyfacts` 에서 **내 식으로 TTM 을 다시 조립했다.** 공식은 `당기 YTD + (선행 FY − 전년 동기 YTD)` 다.

```
AAPL   466,823 / 154,859      창 2025-09-27 FY + 2025-09-28~2026-06-27 − 2024-09-29~2025-06-28
AMZN   775,680 /  93,712      창 2025-12-31 FY + 2026-01-01~2026-06-30 − 2025-01-01~2025-06-30
NVDA   302,970 / 197,579      창 2026-01-25 FY + 2026-01-26~2026-07-26 − 2025-01-27~2025-07-27
TSLA   103,619 /   4,372
PLTR     6,156 /   2,635
META   228,247 /  86,926
GOOGL  445,866 / 147,628
```

**일곱 개사 매출·영업손익 열네 개 값이 전부 일치한다.**

**MSFT·ORCL 의 "공시값 자체" 주장도 확인했다.** 두 회사만 최신 태깅 연간 창이 곧 TTM 창이라 복원이 필요 없다.

```
MSFT  2025-07-01~2026-06-30   331,839 / 155,237   FY 태깅값과 동일
ORCL  2025-06-01~2026-05-31    67,357 /  20,606   FY 태깅값과 동일
```

**`F6-SPEC-18` 에서 확인된 구조가 영업손익에서도 그대로 재현됐다** — 회계 Q4 가 막 닫혀 FY 가 공시된 회사에서만 창이 FY 와 겹친다. 규약 `[A]` 를 영업손익에 적용한 판단이 맞다.

**BABA 연간값도 `G1-TTM-26` 과 일치한다.**

## 틀린 것 — SPCX 는 "회사가 공시하지 않았다" 가 아니다

보고서가 이렇게 적었다.

> **1개사 신규 상장 공시 없음 확정**: SPCX … '**회사가 공시하지 않았다**'로 분류

**거짓이다. 그리고 반증이 `C-13/validation/offb-24/_raw/spcx_s1a_20260603.htm` 안에 있다.** OFFB-24 에서 직접 내려받아 커밋한 파일이고, 거기서 미개시 리스 `$1,627M` 을 뽑아 썼다.

그 파일의 **감사받은 연결손익계산서**다.

```
                                Year Ended December 31,
                                  2025      2024      2023
Revenue                         18,674    14,015    10,387
Total costs and expenses        21,263    13,549    13,892
Income (loss) from operations   (2,589)      466    (3,505)
```

`companyfacts` 에 연간 행이 없는 것은 사실이다. **그러나 그것은 "XBRL 연간 팩트가 없다" 이지 "회사가 공시하지 않았다" 가 아니다.** AMZN 의 `parse_failed` 와 `not_disclosed` 를 갈라낸 것이 바로 그쪽인데, 같은 구분이 여기서 무너졌다.

### TTM 이 산출된다

`companyfacts` 의 반기 행과 S-1/A 의 연간값을 합치면 같은 공식이 그대로 돈다.

```
성분   FY2025      18,674 / -2,589      (S-1/A 감사 손익계산서)
     + 2026 H1    12,508 / -2,086      (10-Q, companyfacts)
     - 2025 H1     8,138 /   -943      (10-Q, companyfacts)
─────────────────────────────────────
TTM 2026-06-30    23,044 / -3,732      영업이익률 -16.195%
```

**baseline 의 `operating_margin_ttm = -14.9%` 는 `legacy_unverified` 였는데, 실측하면 `-16.20%` 로 1.30%p 어긋난다.**

**점수는 안 바뀐다.** 재척도 밴드에서 `-30% ≤ m < -10%` 라 둘 다 `-3` 이다. **그러나 "밴드가 넉넉해 안 갈렸다" 와 "값이 맞다" 는 다르다.** `F6-SPEC-18` 에서 palantir PER 이 10이나 벌어졌는데 밴드 때문에 안 갈렸던 것과 같은 자리다.

### 이것이 세 번째다

| 라운드 | 사실 | C-13 이 적은 것 |
|---|---|---|
| OFFB-24 | BABA 20-F 에 `not yet commenced` 0건 | "회사가 공시하지 않았다" → **물림** |
| G1-TTM-26 | 현재 FPI 라 10-Q 의무 없음 | "**영구적**으로 불가능" → **물림** |
| **G1-FILL-27** | `companyfacts` 에 SPCX 연간 행 없음 | **"회사가 공시하지 않았다"** |

**패턴이 같다 — 확인한 범위 안의 부재를 세상의 부재로 옮긴다.** 그리고 이번은 **반증이 자기가 두 과제 전에 커밋한 파일 안에 있었다**는 점에서 앞의 둘보다 무겁다.

`missing-label-finding.md` 가 가르친 것이 정확히 이것이었다 — **"미확인" 이라 적힌 값이 이미 저장소 안에 있었다.** 그 교훈을 얻은 바로 다음 과제에서 **같은 파일로 같은 실수를 했다.**

## 둘째 — TSM 이 21개월 묵었다

```
TSM   annual   2024-01-01 ~ 2024-12-31    NT$ 2,894,308M / 1,322,053M
```

기준일이 `2026-09-02` 인데 **FY2024** 다. `companyfacts` 의 최신 연간 행이 거기서 끊긴 것은 맞다(`F6-FX-16` 에서 확인된 FY2025 결측).

**그러나 `F6-FX-16` 검토에서 TSM 의 EDGAR 원문 우회를 세 조건으로 허용했다** — 우회 사실을 관측에 기록, 겹치는 연도로 두 경로 검산, `companyfacts` 반영되면 복귀. **그 우회를 쓰지 않았고, 표에 `annual` 이라고만 적혀 21개월 격차가 드러나지 않는다.**

BABA 는 `2026-03-31` 로 6개월 전인데 TSM 은 21개월 전이다. **같은 `annual` 라벨 아래 성질이 다른 두 값이 들어가 있다.**

## 보완 셋

**1. SPCX 분류를 고치고 TTM 을 산출하라.** `not_disclosed` 가 아니다. `companyfacts` 에 연간 XBRL 팩트가 없다는 사실과, S-1/A 에 감사받은 FY2025 손익계산서가 있다는 사실을 **따로** 적어라. 그리고 위 성분으로 TTM 을 조립하고 **`legacy` 값 `-14.9%` 와 1.30%p 어긋난다는 것을 보고에 남겨라.**

S-1/A 가 `companyfacts` 밖이므로 **파생 성분 보존 조건이 더 중요하다.** 세 성분의 출처(문서·페이지·접수번호)를 각각 남겨라.

**2. TSM 기준일 격차를 표에 드러내라.** `annual` 옆에 관측 기간 종료일과 **기준일 대비 경과 개월**을 적어라. EDGAR 우회를 이번에 실행할지는 **하지 마라** — 별도 과제로 분리한다. 지금은 격차가 보이게만 하면 된다.

**3. "공시 없음" 이라는 말을 쓸 때 무엇을 확인했는지 한 줄로 적어라.** `companyfacts` 만 봤으면 "`companyfacts` 에 없다" 라고 쓰라. 세 라운드 연속으로 같은 자리에서 미끄러졌다.

## 평가

**수치 작업은 흠잡을 데가 없다.** 열네 개 값을 독립 복원해 전부 맞췄고, 파생 성분을 보존했으며, MSFT·ORCL 의 FY 일치를 스스로 검산했다. **틀린 것은 계산이 아니라 "없다" 를 적는 방식이다.**

**그리고 이 과제가 목표한 것은 달성됐다.** 10개사가 수치 없이 검토 부호로 G1 을 통과하던 상태가 끝난다. 영업이익률이 `+4.22%`(TSLA)에서 `+65.21%`(NVDA)까지 실측으로 깔렸다.
