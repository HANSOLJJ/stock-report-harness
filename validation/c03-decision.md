# C-03 확정 — F2 경로 수→점수 매핑

- 확정일. 2026-09-14.
- 결정자. 사용자.
- 근거. C-13 `0261744` 3차 보완 · 설계진행 독립 재현.

## 결정 1 — 혼합 모델 채택

```
경로 0개→2, 1개→3, 2개→4, 단 성능 도약이 '세대 격차' 수준이면 5
```

**사다리의 5점 칸 하나만 교체한다.** `AA 종합 1위` → `성능 도약 세대 격차`.

```
사다리 단독  12/14   NVIDIA·TSMC 각 -2
질 단독      14/14   3점 칸을 사다리에서 빌림
혼합         14/14   ← 채택
```

### 왜 사다리가 틀렸나 — HANDOVER 는 규칙이 아니다

표 머리글이 답이다.

```
| factor | 기계화 정도 | 지표 | 산식·사다리 | 사람이 판정할 것 |
| ② 게임체인저 | 반 | … | 경로 0개→2 … AA 종합 1위→5 | 경로 통과 여부 (성능 경로는 AA 순위로 기계화 가능) |
```

**같은 행이 스스로 `성능 경로는 AA 순위로 기계화 가능` 이라고 적는다.** 사다리는 채점규칙 별표 F 의 **기계화 제안**이고, `세대 격차`(판단)를 `AA 종합 1위`(조회)로 바꿨다. **손실이 5점 칸에서 났고 그 경위가 같은 행에 기록돼 있다.**

별표 F 가 규칙이고, 그 예시 칸이 **같은 경로 하나 안에서 5와 4를 가른다** — NVIDIA ②5 · Anthropic ②5 · Meta ②4. **규칙 문서 자신이 `경로 하나로 5점` 을 대표 예시로 든다.**

### 등재할 제약

채점규칙 370~387행이 `세대 격차` 판정을 제약한다 — `두 축이 갈리면 둘 다 적는다`, `벤더 발표는 1차 근거가 아니다`. **세 축 중 몇 개에서 서야 하는지는 원문 미규정**(C-13 실측). 그 사실도 같이 등재한다.

## 결정 2 — anthropic ②5 를 지금 재검토

원문 작성자가 스스로 고지하고 요청한 재검토다.

> ⚠️ **이해상충 고지** — … **결과적으로 Anthropic ②5를 지켰다.** 작성자(Claude)가 Anthropic 모델이므로 운영이력 긴장 #4·#11에 기록하고, **다음 분기에 제3자 관점으로 재검토**한다.

발동 조건이 이미 적혀 있다.

```
HANDOVER 118행  긴장 #11  독립 기관의 에이전트 실무 축 측정 → ② 5→4 조건
HANDOVER 118행  긴장 #10  Anthropic 훈련 컴퓨트가 AWS 단일 → ⑧ -3→-4 조건
둘 다 발동 시   anthropic 12 → 10 (5위 → 7위)
```

### 누가 하는가 — 밝혀 둔다

**나도 Claude 이고 worker·NTM 도 Claude 다. 원문 작성자와 같은 이해상충을 그대로 갖는다.** C-13 워크트리만 다른 모델로 돌아 **이 프로젝트에서 `제3자 관점` 에 가장 가까운 자리**다. 그곳에 배정했고, 지시서에 **"제 앞선 제언과 어긋나는 결론이 나오면 그대로 내십시오"** 를 명시했다.

**자료 제약은 그대로다.** 허용 원천(SEC·연준)에 벤치마크 자료가 없다. 저장소와 v1.5 원본 안의 독립 기관(AA) 측정치로만 판정하고, 못 구하면 못 구했다고 적게 했다. **`판정 불가` 도 유효한 답이다.**

## 결정 3 — F2 0·1점 조건 신설

사용자가 `신설` 을 택했다. **다만 질문 뒤에 전례를 찾았다.**

```
F3 range [1,5]   사다리 "통과점 1→2 …"        바닥 2, 범위 하한 1
F2 range [0,5]   사다리 "0개→2 …"             바닥 2, 범위 하한 0
```

**F3 는 범위 하한이 사다리에 맞춰 좁혀져 있고 F2 만 안 좁혀져 있다.** 그래서 신설 전에 F3 가 언제·왜 좁혀졌는지와 F1·F4·F5 의 사다리 바닥을 먼저 확인하게 했다. **F2 만의 문제인지 여러 factor 공통인지가 갈린다.**

**경로 수 모델에서 0·1 은 구조적으로 나올 수 없다** — 경로 0개가 이미 최소이고 그것이 2점이다. 0·1 을 만들려면 **경로 수가 아닌 다른 축**이 필요하고, 그 축을 명시하지 않은 신설안은 받지 않는다.

신설안은 **제안까지**다. 1·2 결과에 따라 사용자에게 다시 올린다.
