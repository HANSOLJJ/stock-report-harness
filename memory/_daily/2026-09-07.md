## Entry: 2026-09-07 — Windows에서 Codex 이미지 래퍼가 cp949 인코딩으로 stdin 쓰기 실패
- **상황**: `ciena-recent-6m-2026-09` 파이프라인 image 단계. Windows 11, venv Python 3.12, `python3 scripts/run_stock_image_codex.py <slug> --codex-bin D:\pgmming\nodejs\codex.cmd` 실행. 직전 커밋 0df7d6e.
- **증상**: `UnicodeEncodeError: 'cp949' codec can't encode character '\u2212' in position 1123: illegal multibyte sequence` (subprocess `_stdin_write`). 매니페스트가 `in_progress` 상태로 남음.
- **원인**: `subprocess.run(text=True)`가 로케일 기본 인코딩(cp949)을 쓰는데 draft에서 가져온 프롬프트에 '−'(U+2212)가 있었음.
- **해결**: `run_codex()`의 `subprocess.run`에 `encoding="utf-8", errors="replace"` 추가함. 재실행 후 `[PASS] stock-image generated via Codex CLI imagegen`.
- **검증**: 재실행으로 hero v1~v3 PNG, score JSON, manifest `complete` 생성 확인함.

## Entry: 2026-09-07 — Codex CLI 실행 파일을 subprocess에서 못 찾는 문제 회피
- **상황**: 같은 image 단계. `codex`는 `D:\pgmming\nodejs\codex.cmd`(npm 전역)로 설치됨.
- **증상**: PowerShell 세션에서 `where.exe codex`가 처음엔 결과 없음. 래퍼는 `codex_bin` 문자열을 그대로 `subprocess.run`에 넘겨 `.cmd` 확장자 없는 이름은 CreateProcess가 해석하지 못할 수 있음.
- **원인**: 추정. npm 전역 bin이 PATH에 늦게 반영됐고, Windows에서는 `.cmd` 래퍼를 전체 경로로 지정해야 안전함.
- **해결**: `--codex-bin D:\pgmming\nodejs\codex.cmd`로 전체 경로 지정함. `shutil.which`도 `.cmd`를 PATHEXT로 인식함.
- **검증**: Codex CLI 0.153.4, `codex login status` = Logged in using ChatGPT, 이미지 3장 생성 성공함.

## Entry: 2026-09-07 — validate_report_contract가 Windows에서 plan_source 경로 불일치로 항상 실패
- **상황**: review 단계 codex-independent 리뷰어가 검증기를 시뮬레이션함.
- **증상**: `research plan_source 불일치: 'plan/…md' != 'plan\\…md'` 류 오류 6건. 빌더 precheck도 같은 함수를 써서 build가 시작되지 않음.

- **검증**: `python3 scripts/validate_report_contract.py ciena-recent-6m-2026-09` PASS 확인함.

## Entry: 2026-09-07 — strip_source_markers가 개행·들여쓰기를 삼켜 stat-card와 중첩 목록이 깨짐
- **상황**: 빌더 `transform_body` 시뮬레이션. 기존 samsung HTML에도 raw `::stat-card`가 남아 있었음.
- **증상**: `compare: … [P1]\n::` → `compare: …::`로 붙어 `STAT_CARD_RE`(`\n::` 필요) 매칭 실패. `    - 요약:` 들여쓰기가 한 칸으로 줄어 python-markdown이 중첩 목록으로 인식 못 함. `[H1]` 표식은 정규식이 S/N/P만 알아 최종 HTML에 잔존함.
- **원인**: `re.sub(r"\s+([.,;:!?])")`의 `\s+`가 개행 포함, `re.sub(r" {2,}", " ")`가 줄 앞 들여쓰기 포함. `SOURCE_MARKER_RE`가 훅(`S|N|P|H|A|F|R`)보다 좁음.
- **해결**: `[ \t]+([.,;:!?])`, `(?<=\S) {2,}`, `SOURCE_MARKER_RE`/`SOURCE_MARKER_PREFIX_RE`에 `H` 추가. 원래 줄은 주석으로 보존함.
- **검증**: 시뮬레이션에서 잔존 표식 0개, stat-card 렌더, 중첩 `<ul>` 렌더 확인함.
