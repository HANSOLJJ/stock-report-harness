결정과 근거의 전문은 plan.md 의 Context 절에 있다. 여기에는 구현 중에 생기는 결정을 이어 적는다.

- 2026-10-12 계기: 사용자 "지금 채점은 기존 빅테크에 너무 유리하다". docs/ai_7.md 검토와 외부 검토 세 차례(사용자가 붙여 넣음)를 거쳐
  ①④⑥⑦⑧ 개정, 현금 연결표, 국면 지표로 정했다. 발굴은 사용자가 하고 하네스는 후보를 공정하게 잰다.
- recheck(v2.0)는 리뷰 통과 상태로 커밋하고 승인하지 않았다. 11월 v2.1 실행이 `init --from-run ai-scorecard-2026-10-recheck` 으로 출발한다.
- 승인된 실행(rescore v1.9, rejudge v2.0)의 결과 해시는 바뀌면 안 된다. 새 동작은 v2.1 규칙 JSON 의 새 키가 있을 때만 켠다.
- 2-A 의 두 축 그림 색은 비교 그룹(2-B 보유표가 정함)이 있어야 하므로 2-B 로 옮긴다. 산점도 자체는 `render_html.scatter_svg` 에 이미 있다.
- ① 판정 재료 여섯 개는 승인 페이지 선택 상자가 아니라 CLI 전용(`judge --json`·`propose --json`)으로 받는다. 승인 페이지 입력란을 늘리면
  v2.0 실행 화면까지 바뀌기 때문이다. CLI 전용 재료가 숫자 목록 하나에서 여러 모양으로 늘어 `JUDGMENT_CLI_ONLY_TYPES` 로 모양을 거른다.
- ① 상한은 범위 자르기 뒤에 댄다. 화면 사다리 줄은 "AI 수익화 '예' 아님 → 상한 4" 로 적어 범위 자르기와 섞이지 않게 했다.
- rules.md 는 2-A(①⑥⑦)를 다 넣은 뒤 한 번에 v2.1 현행 문장으로 고친다. 그 전에는 머리말이 v2.0 이다.
