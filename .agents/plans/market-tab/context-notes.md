# 지금 시장 탭 결정 기록

- **2026-11-15 별도 주소 대신 리포트 안 탭.** 별도 주소(fin.hansoljj.com/market/)는 리포트와 섞이지 않는 장점이 있었지만 사용자가 한 화면에서 보기를 골랐다. 옛 리포트에 오늘 값이 떠 헷갈리는 문제는 기준일 값과 지금 값을 나란히 두고 변화를 보여 정보로 바꾼다.
- **지금 값은 실행 파일에 쓰지 않는다.** 확인된 리포트는 입력 해시에 묶인 고정본이라, 갱신 버튼의 값이 들어가면 점수가 무엇을 보고 매겨졌는지 흐려진다. 고정 기록은 collect 가 찍는 기준일 값뿐이다.
- **정적 HTML 이 원천을 바로 부르지 않는다.** 다른 도메인 요청 차단과 키 노출 때문에 맥미니 리포트 서버가 받아 캐시한다.
- **2026-11-15 지금 값은 공개 사이트의 기존 중계 주소를 쓴다.** 새 server.js 엔드포인트와 캐시를 만들지 않았다. 공개 사이트에 이미 있는 `/api/proxy` 가 FRED API 키를 넣어 주고, OpenRouter 는 다른 도메인 요청을 허용해 브라우저가 바로 부른다. vast.ai 는 그 프록시 허용 목록에 없어 지금은 "허용하지 않는다"로 보인다. 허용 목록은 finance 저장소라 이 저장소에서 고치지 않는다. 로컬·파일로 열면 중계 주소가 없어 FRED·GPU 칸은 "공개 주소에서 열어야" 로 보인다.
- **기준일 값의 날짜는 원천마다 다르다.** FRED 는 지난 값을 받을 수 있어 가격 기준일 이하 최근 값이고, vast.ai·OpenRouter 는 지난 값을 받을 수 없어 받은 날 값이다. 표의 값 날짜 칸이 그 차이를 보인다.
- **토큰 혼합 단가는 Silicon Data 지수와 다른 지표다.** 기존 `token_price_index`(수동, 거래 기반 지수)는 그대로 두고, 새 `token_blended_price` 는 OpenRouter 정가로 연구소 일곱 곳(openai·anthropic·google·x-ai·deepseek·qwen·moonshotai)의 최근 180일 최고가 텍스트 모델을 입력 3 : 출력 1 로 섞은 단가의 중간값이다. 동점은 더 최근 모델, 그다음 이름 순. 날짜는 UTC 로 잘라 파이썬과 브라우저가 같은 모델을 고른다.
- **GPU 임대료는 GPU 수 가중 중간값.** 호가 하나의 GPU 장수만큼 한 장 단가를 반복해 중간값을 낸다. 8장 묶음 하나가 1장 호가 여럿보다 덜 무시되게 하려는 것이다. 호가가 없으면 값을 만들지 않는다(0 아님).
- **스크립트 자산은 렌더 때 인라인한다.** 단일 파일 리포트라 `assets/market_live.js` 를 `<script>` 로 넣는다. 용어 링크 후처리가 `<script>` 태그만 건너뛰므로, 기준일 값은 JSON 블록이 아니라 표 행의 data 속성에 둔다.
- **2026-11-15 2차: 지금 값 하나에서 추이로.** 사용자가 추이, 역사가 긴 지표는 10년까지를 원했다. FRED 의 ICE BofA OAS 는 최근 3년만 내주므로 무디스 Baa−10년물(BAA10Y, 정의가 단순 금리 차)을 10년 추이용으로 더하고 OAS 도 남긴다(사용자 선택). GPU·토큰은 원천이 과거를 주지 않아 오늘부터 매일 쌓고, GPU 는 GetDeploying 무료 데이터(53주, 공급자 96곳 중간값)를 별도 선으로, 토큰은 OpenRouter 지금 목록 재구성(2025-07~, 치우침 표시)을 별도 선으로 둔다(사용자 선택). 재구성을 2025-07 에서 자른 것은 그 전에는 연구소 1~4곳만 잡히고 소형 모델이 골라져 지표 구실을 못 해서다.
- **공개 리포트는 /api 를 부를 수 없다.** `/reports` 만 Access 우회이고 `/api/*` 는 로그인이 필요하다. 1차 설계의 `/api/proxy` 호출은 로그인한 소유자에게만 됐다. 서버가 모아 `/reports/market-series.json` 로 내보낸다. FRED 는 서버가 fredgraph.csv 로 받으므로 키도 필요 없다.
- **2026-11-15 차트는 TradingView Lightweight Charts(사용자 지정).** 저장소에 설치하지 않고 버튼을 누를 때 jsDelivr 에서 `lightweight-charts@5.2.1` standalone 을 불러온다. 5.3.0 은 나온 지 5일이라 피했다. `integrity="sha384-KkYqTZlM13Zya6fVUF3IGCBOQ1ehFeJVVgxaVvD/0MebineF9EI8Jkd3NnWNChqN"` 로 고정해 CDN 파일이 바뀌면 불러오지 않는다. - **2026-11-15 배포는 하네스 main 빨리감기를 함께 했다.** 맥미니 하네스 clone 은 fork 의 main 을 따르고, finance 서버가 그 clone 의 `market_live.js` 를 불러 쓴다. `draft/rules-v3.0` 이 main 위에 계획 문서와 시장 지표 커밋만 얹은 상태라 main 을 빨리감기해 fork 에 푸시했다. 이 파일을 고치면 하네스 main 을 맥미니에 받은 뒤 `pm2 restart finance` 를 해야 서버가 새 정의로 받는다.
