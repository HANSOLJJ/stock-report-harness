- **① 구조화 방향(초안, 사용자 확정 대기).**
  - 입력 1: 실질 채널 목록(매출·사용자 기여가 유의미한 것만). 소비자/업무/거래. "부품"은 채널이 아니라 고객이 조직인 업무 채널로 본다.
  - 입력 2: 가장 강한 채널에 대해 네 질문. 각각 pass/partial/fail/unknown + EV 표지.
    - 회수 루프: 사용자·개발자가 늘수록 기존 사용자 편익이 느는가. (CUDA 생태계, 검색 데이터 루프, 앱 스토어 양면성)
    - 전환비용: 바꾸는 비용·시간이 큰가. 실제 이탈 사례가 있으면 fail 쪽. (PDK 재설계, 기간계 DB, Palantir 영국 경찰 이탈)
    - 대체 공급: 대체재가 출하되고 성능 격차가 좁은가. 좁으면 fail. (TPU 외부 판매, ROCm, Intel 14A·Samsung 2nm)
    - 가격 실측: 가격을 올리거나 할인 없이 유지했는데 고객이 남았는가. 총마진 추세, 정가 인상 후 이탈, $/M 대비 점유율. 이 입력은 매달 관측으로 다시 재는 칸이다.
  - 입력 3: 지속성 할인. 고객 집중(10-K 10% 이상 고객 공시)이 높고 그 고객의 자체 대체재가 실제 출하 중이면 −1. 채널 유형과 무관하게 적용.
  - 사다리 초안(프로그램 계산): 5 = 가격 실측 pass 이고 회수 루프·전환비용 중 하나 pass. 4 = 회수 루프·전환비용 중 하나 pass, 가격 실측 partial/unknown. 3 = 하나 partial 이상이고 대체 공급 fail 아님. 2 = 거래 채널만이거나 전환비용 partial 뿐. 1 = 락인 근거 없음·이탈 관측. 0 = 실질 채널 없음. 할인 −1 은 5→4 까지만. unknown 은 0.5 로 채우지 않고 점수를 만들지 않는다(③과 같은 원칙).
  - 5점에 가격 실측을 요구하는 것은 rules.md 58행("① 5점 = 가격 결정력 실측")과 이미 맞는다. 이 입력이 관측 기반이라 매달 다시 재는 이유가 생긴다.
  - ③ 모방 불가능성의 "①의 설치기반이라 안 센다"는 그대로 둔다. ①에서 세기 시작하면 중복 금지가 바르게 작동한다.
- **전환비용 pass·partial 의 정의(2026-10-08, TSMC 를 따져 보다 나옴).** pass = 비교 가능한 대체재가 **있는데도** 고객이 남는 것이 관측됨(관계 수준 락인). partial = 지금 설계·계약 동안만 묶이고 다음 선택 시점에 다시 고르며, 대체재가 생기면 옮긴 사례가 있음(설계·계약 수준 락인). fail = 이탈 관측. 이 정의로 TSMC 는 partial 이다 — PDK 재설계 비용은 크지만 노드마다 다시 고르고, Apple 은 2016 년 Samsung 에서 옮겨 왔고 NVIDIA 는 Ampere 소비자 GPU 를 Samsung 8nm 으로 냈다가 돌아왔다. 고객이 남는 이유가 "옮길 데가 없어서"면 그건 ③ 모방 불가능성(공급 쪽 자산)이 이미 세는 것이고, ① 가격 실측 pass 가 그 자산의 결과물일 뿐이면 ① 과 ③ 이 같은 속성을 두 번 세는 것이 된다(rules.md 36). 그래서 5 점은 관계 수준 락인(회수 루프 또는 전환비용 pass)이 있어야 하고, 공급 부족에서 나온 가격결정력만으로는 4 에서 멈춘다. Oracle DB 는 Postgres 가 수십 년 있었는데도 남으니 pass, CUDA 는 ROCm 이 있는데도 개발자가 남으니 pass, Microsoft M365 는 Workspace 가 있는데도 남으니 pass. TSMC 가늠은 회수 루프 partial(OIP) · 전환비용 partial · 대체 공급 pass(보정 없음) · 가격 실측 pass → 3+1 = **4**(합계 11→13, 3 위권). 앞서 적은 5 는 전환비용을 pass 로 본 것이라 철회한다.
- **영향 가늠(판단 아님, 검증 안 됨).** 네 질문대로면 TSMC(PDK 전환비용 pass·대체 공급 fail 아님·가격 인상 실측 pass, 집중 할인 가능)와 NVIDIA(CUDA 회수 루프 pass·가격 실측 pass·대체 공급 partial, 집중 할인 −1)는 2 → 4 근처, Palantir(전환비용 partial, 이탈 관측)는 2 유지 또는 1, Oracle(DB 전환비용 pass, 가격 실측 unknown)은 3~4, Microsoft(업무 전환비용 pass, M365 가격 인상 실측)는 5 유지. 합계로는 TSMC 11→13(3위권), NVIDIA 9→11(5위권). 순위가 바뀌는 변경이므로 영향 검사를 먼저 하고 사용자가 사다리를 확정한다.
