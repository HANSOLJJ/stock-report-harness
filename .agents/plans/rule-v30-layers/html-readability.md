# 14개사 리포트 HTML 가독성 수정 계획 (2026-10-20)

## 왜

승인·build 뒤 사용자가 리포트를 보고 짚은 문제다.

- 항목 점수 옆에 만점이 없어 12 가 높은지 낮은지 알 수 없다.
- 카드 머리의 층별 점수 표는 머리글이 ①②③ 기호뿐이라 무엇의 점수인지, 회사 점수와 어떻게 이어지는지 보이지 않는다.
- ① 시장 위치 표(D·E)가 ① 의 일부인데 카드 머리에 9개 항목과 같은 높이로 떠 있어 별도 항목처럼 보인다.
- A·B·C·D·E 의 뜻이 리포트 어디에도 없다. ②③ 도 층 점수를 이루는 세 부분이 화면에 없다.
- 열한 층 보유표가 오른쪽으로 잘려 주 층·AI 무관 매출·④ 열이 있는 줄 모른다.

## 원칙

- HTML 렌더러(`scripts/scorecard/render_html.py`)만 고친다. 초안(draft.md)은 승인 해시에 들어가므로 건드리지 않는다. HTML 은 승인 해시 밖이라 다시 승인하지 않고 build 만 다시 돌린다.
- 새 표시는 층 규칙(v3.0, `rc.is_layered`) 실행에서만 탄다. 옛 실행의 화면은 바꾸지 않는다(기존 관례).
- 값은 모두 `results.json` 의 calc 에서 읽는다. 만점·미확인 비율·관문은 규칙 파일에서 읽는다.
