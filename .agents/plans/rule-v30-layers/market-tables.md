# 시장 정의표와 ① D·E 계산 (규칙 v3.0)

## 왜

① 네트워크의 D 시장 순위·E 점유율 방향은 시장 정의표가 없어 모든 사업이 미확인(각 1.6)이다. 그래서 시범 순위를 판단에 쓸 수 없고 기준선 80·56 도 잠정으로 두었다(2026-10-15 사용자 결정). 사용자가 "일단 진행해봐"로 착수를 정했다(2026-10-15).

## 무엇을 만드나

1. **정의표 파일** `scorecard/markets/<market_id>.json`: 시장 이름, 측정 단위(매출·출하 대수·가입자), 기간 기준, 구성 회사, 구성 밖 대형 사업자, 1순위·대체 출처, 기간별 값(회사마다 값·근거 ID·출처). 규칙 JSON 이 파일 해시를 품어 점수를 본 뒤 시장을 바꿀 수 없다(rules.md ① 「D·E 의 시장」).
2. **계산** `scripts/scorecard/calc_market.py`: 최근 기간과 1년 전 기간에서 순위·점유율을 내고 D(0~4)·E(0~4)를 매긴다. 반올림 경계에서 D 칸이 갈리면 확정하지 않고, E 는 범위 양 끝 가운데 낮은 쪽. 자료가 빠지거나 기간이 안 맞으면 미확인 1.6.
3. **연결**: 사업 판단의 구성(`components[].market`)이 시장 id 를 가리키고, `compute_f1_business` 가 정의표에서 D·E 를 읽는다. 묶음은 구성마다 재서 매출 몫으로 합친다.
4. **검증**: 정의표 스키마, 규칙 JSON 의 해시 대조, 판단이 가리키는 시장이 정의표에 있는지.
5. **자료 수집**: 시범 5개사 시장 8~10개. 시장마다 최근 값과 1년 전 값을 원문으로 모아 근거로 확정한다(Sonnet 세션, 시장 범위 판단은 규칙대로).
6. **렌더**: 초안에 시장·순위·점유율 변화와 구성 밖 사업자 표시.

## 검증

- 단위 테스트: 순위 4·3·2·1·0 칸, 2배·50% 조건, E 비례(−2·0·+2%p), 반올림 경계 미확정, 범위 낮은 쪽, 자료 빠짐 → 1.6, 해시 불일치 거부, v2.x 실행 불변(승인 실행 재계산 테스트).
- 시범 실행을 새 실행으로 이어받아 D·E 가 들어간 점수로 다시 계산한다.

## 범위 밖

- 14개사 전체 시장, HTML 리포트, 락인이 약한 사업의 D·E 조정(8절 미결).
