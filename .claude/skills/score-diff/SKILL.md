# 채점 실행 불변성 검증 스킬

이전 실행과 비교하여 기존 기업의 관측·판단(1층) 및 점수·순위(2층)가 변경되지 않았음을 기계적으로 검증한다.

## 절차

1. 비교할 대상 실행(`slug`)과 기준 실행(`--against`)을 확인한다.
2. 실행한다:
   ```
   uv run --frozen python -X utf8 scripts/scorecard_cli.py diff <slug> --against <이전 slug> [--json]
   ```
3. 층별 결과를 읽어 보고한다 (1층: 관측·판단·출처 보존, 2층: 점수 투영·순위 불변).

## 제약

- 1층은 조사 직후에, 2층은 계산 직후에 의미가 있다. 두 번 돌린다.
- subtree 해시 차이는 실패가 아니다. 기준일만 바꿔도 달라진다. 불변은 점수 투영으로 판정한다.
- 1층·2층 위반이 하나라도 있으면 종료 코드가 1 이다. 그때는 기업 추가 실행의 축약 리뷰를 쓸 수 없다.

## 완료 보고

층별 통과·위반, 신규 기업 목록, 기준일 판정, 이전 실행의 승인 유효 여부.
